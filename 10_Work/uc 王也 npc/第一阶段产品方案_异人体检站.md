## 0. 一句话

> **公测前 8~4 周，通过「王也 AI 体检站」让预约玩家在 3 分钟内完成一次"被王也读懂"的体验，产出两份社交分享物，实现自传播裂变 + 预约转化。**

---

## 1. 问题陈述

### 1.1 要解决什么问题

《一人之下》手游是**结合一人之下 IP 的 1v1 硬核格斗游戏**。预约量已破 2500 万，公测前需要：

1. **激活沉默预约用户** — 2500 万预约中大量是"点了就忘"，需要在公测前重新唤醒
2. **建立情感连接** — 格斗游戏的核心用户关注操作手感，但 IP 用户关注角色魅力。需要同时满足两类人
3. **裂变拉新** — 从预约用户向泛游戏/泛国漫圈扩散

### 1.2 为什么是这个方案

| 方案 | 优势 | 劣势 | 结论 |
|------|------|------|------|
| 纯 AI 对话（聊天） | 开发成本低 | 无明确目标感，用户聊几句就走 | ❌ 留不住人 |
| 纯人格测试（问卷） | 产出物好看 | 入口门槛高（谁愿意先答 7 题？） | ❌ 进不来人 |
| **漏斗式体验（先 ID 批命 → 再深度体检）** | 零门槛进入 + 好奇心驱动深入 + 双分享物 | 开发复杂度中等 | ✅ **本方案** |

### 1.3 关键约束

- **游戏定位**：1v1 硬核格斗 — 不是 MMO，不是纯 IP 恋爱向。体检内容必须同时覆盖 **IP 人格** 和 **格斗属性**
- **IP 属性**：王也是国漫顶流角色 — 人设还原度是核心粉底线，不容许"出戏"
- **格斗属性**：游戏玩法是硬核格斗 — 体检报告要让玩家感受到"我在格斗游戏里是什么样的人"，不只是"我是什么门派"

## 3. 非目标（明确不做什么）

- ❌ **不做开放式闲聊** — 本阶段体检站是有目标的结构化体验，不是漫无目的的 AI 聊天
- ❌ **不做游戏内功能** — 本阶段是独立 H5/小程序，不依赖游戏客户端
- ❌ **不做多角色** — 本阶段只做王也，冯宝宝/张楚岚留给后续阶段
- ❌ **不做每日算命** — 留存钩子放在报告底部做入口预埋，但完整功能留给第二阶段
- ❌ **不做 AI 语音/TTS** — 本阶段纯文字交互，降低技术风险和成本

### 4.2 双分享物设计

| 分享物 | 生成节点 | 形态 | 适合平台 | 传播场景 |
|--------|---------|------|---------|---------|
| **批命卡** | STEP 1 | 方图 / 短图（1:1 或 3:4） | 朋友圈、微博、短视频评论区 | "王也吐槽我的 ID 笑死" — 15 秒看完 |
| **体检报告** | STEP 3 | 长图（9:16 竖版） | 小红书、QQ 空间、微信聊天 | "我的异人体检报告出来了" — 细读+讨论 |

**设计原则**：
- 两个分享物**视觉风格统一**（都是「异人体检站」品牌），但**信息密度不同**
- 批命卡 = **5 秒看完**，核心是王也的一句吐槽 + 星级
- 体检报告 = **30 秒细读**，核心是完整的格斗画像 + 人格分析 + 深度评语

## 5. STEP 2 详细设计：7 轮情景对话

### 5.1 设计原则

1. **不是问卷，是王也跟你聊天** — 每轮都有即时反馈，不是"请选择 A/B/C"
2. **前 2 轮轻松，后 5 轮递进** — 降低弃出率
3. **兼顾 IP 属性和格斗属性** — 不只是"你是什么门派"，还有"你的格斗风格是什么"
4. **每轮 ≤ 2 个选项 + 1 个自由输入** — 不给决策疲劳
5. **AI 动态追问** — 基于上一轮回答调整语气和追问方向

### 5.2 七轮问答详细设计

#### 第 1 轮：破冰（测应激反应）

```
王也：
"你走在路上，突然看到有人头顶冒出奇怪的光。你会？"

选项：
A. 假装没看到，加速走开
B. 直接走过去看清楚
C. [自由输入]

AI 回应示例：
选 A → "跑得倒是快。但格斗场上背对敌人可不是好习惯。"
选 B → "胆子不小。不过光有胆子没有拳头，在异人世界活不过三集。"
```

**测量维度**：应激反应（战/逃/冻结）  
**格斗映射**：进攻型 / 防守型 / 观察型  
**深度**：浅（破冰，降低弃出率）

#### 第 2 轮：价值观（测异能观）

```
王也：
"如果你突然觉醒了异能，第一件事做什么？"

选项：
A. 想办法变强
B. 先搞清楚怎么回事
C. [自由输入]

AI 回应示例：
选 A → "急。练武之人最忌心浮气躁。但你这股劲儿，适合进擂台。"
选 B → "沉得住气。武当欢迎你这种人——虽然你可能待不了三年。"
```

**测量维度**：价值观（力量导向 / 理性导向 / 利己导向）  
**格斗映射**：力量型 / 技术型 / 机会型  
**深度**：浅（仍在破冰）

#### 第 3 轮：格斗风格（新增 · 贴合游戏类型）

```
王也：
"格斗场上，对手比你壮两圈。开局你怎么打？"

选项：
A. 正面硬刚，气势不能输
B. 先拉开距离，找破绽再动手
C. [自由输入]

AI 回应示例：
选 A → "硬碰硬？有种。不过在一对一的擂台上，
        蛮力能赢一时，赢不了一世。"
选 B → "道家讲的就是这个——后发先至。
        不过别观察太久，等你想好的时候可能已经躺了。"
```

**测量维度**：格斗风格偏好（压制型 / 反击型 / 灵活型）  
**格斗映射**：直接影响报告中的「战斗风格」标签  
**深度**：中（开始进入游戏核心话题）

#### 第 4 轮：抗压与执念（测修行观）

```
王也：
"王也邀你入武当修行，条件是三年不能下山。
 期间每天练拳八小时。你来吗？"

选项：
A. 来。三年换一身本事，值了
B. 不去。三年太长，我自己练
C. [自由输入]

AI 回应示例：
选 A → "能吃苦是好事。但武当不只是练拳——
        你得先学会什么都不干地坐一天。
        这个比打架难多了。"
选 B → "自己练？行，有主见。
        不过格斗这事儿，没人喂招你怎么进步？
        闭门造车出不了高手。"
```

**测量维度**：耐性 / 执行力 / 独立性  
**格斗映射**：团队训练型 vs 野路子型  
**深度**：中

#### 第 5 轮：道德灰度（测忠义观）

```
王也：
"甲申之乱中，你的师兄叛变了。
 但你知道他是为了救自己的家人。
 擂台上你们相遇了。你怎么打？"

选项：
A. 全力以赴，叛就是叛
B. 先问清楚再动手
C. [自由输入]

AI 回应示例：
选 A → "杀伐果断。格斗场上确实不该犹豫。
        但你确定他出拳的时候，不会留手？"
选 B → "擂台上没时间问问题，对手不会等你。
        不过……你这种人，赢了也不会得意。
        这是好事。"
```

**测量维度**：忠义观 / 灰度思维  
**格斗映射**：冷血型 / 情义型  
**深度**：深

#### 第 6 轮：性格底色（测孤独观）

```
王也：
"格斗是一个人的事。
 擂台上没有队友，只有你和对手。
 你更怕——一个人上场，还是所有人都在看你？"

选项：
A. 怕一个人上场
B. 怕所有人看着
C. [自由输入]

AI 回应示例：
选 A → "那你不适合修道。道这条路很长，也很安静。
        但格斗场上的孤独，和修行的孤独不一样——
        前者只需要你扛住三个回合。"
选 B → "怕被看？那倒有意思。
        真正的高手出招的时候不在乎观众，
        他只看对面那个人。
        你得练到那个境界。"
```

**测量维度**：性格底色（内向/外向 × 抗压能力）  
**格斗映射**：独狼型 / 表演型  
**深度**：深

#### 第 7 轮：自我认知（核心题 · 开放式）

```
王也：
"最后一个问题。
 给自己三个字的评价。"

[自由输入框]

AI 回应（基于前 6 轮综合分析）：
示例——用户输入"不服输"：
"不服输？跟你前面的回答倒是对得上。
 你选了正面硬刚、选了全力以赴、还说怕一个人上场——
 你不是不服输，你是怕输了没人看到你赢。
 不过没关系，格斗场上最怕的不是输，
 是不敢上场。
 你敢。这就够了。"
```

**测量维度**：自我认知 × 与前 6 轮回答的一致性  
**格斗映射**：AI 综合判定最终格斗人格  
**深度**：核心（开放题，让用户感觉"AI 真的在理解我"）

### 5.3 王也追问的动态逻辑

**核心规则**：王也的每一轮回应都必须**引用/回扣用户之前的回答**，制造"他真的在听"的感觉。

```
示例追问链条：

第 3 轮选了"正面硬刚" 
    ↓
第 4 轮王也追问时插一句："你之前说格斗要正面硬刚，
    那三年枯燥修行你扛得住吗？打架靠的不只是勇。"
    ↓
第 5 轮无论选什么，王也说："你第 3 轮说硬刚，
    第 5 轮又说要先问清楚——人在不同处境下会变。
    这才是真实的。"
```

**技术实现**：问诊 Agent 维护一个 `conversation_context` 对象，包含前序所有回答和标签，每轮生成回应时注入上下文。

}

### 8.2 Agent 1：批命 Agent

**定位**：STEP 1 的 AI 后端。输入 ID → 输出吐槽 + 双星级。

**Prompt 核心要素**：
```
[角色] 你是王也，道家修行者，嘴损但不恶毒。
[场景] 你在异人体检站当"鉴定师"，有人来报名。
[任务] 根据对方的 ID/名字，用 1-3 句话吐槽，风格如下：
  - 道家视角：用道家哲学解读名字
  - 格斗视角：从名字联想格斗能力或格斗风格
  - 嘴损但有温度：毒舌是外壳，内核是认可或鼓励
[输出格式] JSON
[约束]
  - 不超过 3 句话（≤80 字）
  - 必须同时包含 IP 元素（道/异人/修行）和格斗元素（拳头/擂台/出手）
  - 绝不输出攻击性/侮辱性内容
```

**双链路方案**：

| 链路 | 触发条件 | 响应时间 | 覆盖率 |
|------|---------|---------|--------|
| 离线预生成 | 命中热门 ID 库（100 万+） | < 1 秒 | ~80% |
| 实时推理 | 未命中预生成库 | < 5 秒 | ~20% |

**离线库构建**：
- 来源 1：游戏预约数据 Top 100 万热门昵称
- 来源 2：常见中文名 Top 10 万
- 来源 3：常见网络梗名 Top 5 万
- 每个 ID 预生成 3 条不同吐槽（避免同名看到一样的）
- 模糊匹配（Jaro-Winkler）：相似名字复用

### 8.3 Agent 2：问诊 Agent

**定位**：STEP 2 的 AI 后端。7 轮对话 → 输出性格向量 + 格斗标签。

**Prompt 核心要素**：
```
[角色] 你是王也，正在对一个来体检的人进行"望闻问切"。
[输入] 上一轮 Agent 1 的批命结果 + 每轮用户回答
[任务] 
  - 按预设的 7 轮问题框架提问
  - 每轮根据用户回答生成 1-2 句即时回应（必须引用前序回答）
  - 第 7 轮综合分析所有回答给出总结回应
[状态维护] conversation_context：记录每轮回答 + 累计标签
[输出]（第 7 轮结束后输出完整向量）
```

**性格向量输出**：
```json
{
  "combat_profile": {
    "attack": 8,
    "defense": 5,
    "reaction": 7,
    "read": 4,
    "pressure": 9,
    "slack": 2,
    "style": "压制型",
    "style_tags": ["#正面刚王", "#不服就打", "#输了再来"]
  },
  "abnormal_profile": {
    "qi_type": "炁体源流·风系",
    "faction": "武当",
    "mentor": "王也",
    "partner": "冯宝宝",
    "enemy": "吕良",
    "personality_tags": ["#外冷内热", "#嘴硬心软", "#社恐但能打"]
  },
  "meta": {
    "self_eval": "不服输",
    "consistency_score": 0.82,
    "key_moments": ["Q3选了正面硬刚", "Q5说先问清楚（矛盾点）"]
  }
}
```

### 8.4 Agent 3：出报 Agent

**定位**：STEP 3 的 AI 后端。汇总批命 + 对话 → 输出报告文案。

**Prompt 核心要素**：
```
[角色] 你是王也，正在为完成体检的人撰写最终报告。
[输入] Agent 1 批命结果 + Agent 2 性格向量 + 7 轮对话原文
[任务]
  - 生成「王也深度评语」（3-5 句，必须引用 ID + 至少 2 个对话中的具体回答）
  - 生成「命运预言」（1 句，结合格斗风格）
  - 检查评语的一致性（不能跟批命阶段矛盾，除非是"反转"叙事）
[输出] JSON 格式的完整报告数据
```

**关键设计**：评语必须制造**叙事弧线感**：
- 首因效应："第一次见你，只看了名字就说你在装"
- 深度认知："现在跟你聊了 7 轮，改主意了——你确实在装，但装得挺像样"
- 格斗鼓励："格斗场上不需要不装的人，需要装到最后自己都信了的人"

## 10. 安全方案

### 10.1 四层防护

| 层级 | 位置 | 措施 | 触发后果 |
|------|------|------|---------|
| **L1** | 前端输入 | 脏词库（5000+）+ 敏感人名库 + 劣迹艺人库 | 拦截 + 提示"换个名字试试" |
| **L2** | AI 输出后 | 混元安全模型实时审核 | 降级到预置兜底回复 |
| **L3** | 兜底 | 200+ 条王也风格通用回复（按场景分类） | 模型异常/超时时使用 |
| **L4** | 运营侧 | 高峰期人工巡检 + 异常对话告警 | 手动下线问题内容 |

### 10.2 特殊场景处理

| 场景 | 处理 |
|------|------|
| 用户输入政治人物名字 | L1 拦截 → "这名字不在三界之内，换一个" |
| 用户输入侮辱性 ID | L1 拦截 → "修行之人不起这种名字" |
| AI 生成跑题内容 | L2 审核 → 降级到兜底回复 |
| AI 响应超时（>10 秒） | 超时中断 → 返回兜底回复 + 前端 loading 动画 |
| 同一用户反复体检 | 每人每天限 3 次完整体检（批命不限） |

## 16. 核心取舍（Trade-off Log）

| 决策 | 选了什么 | 放弃了什么 | 理由 |
|------|---------|-----------|------|
| 格斗 vs 纯 IP | **兼顾：格斗画像 + 异人人格双模块** | 纯 IP 人格测试 | 游戏是 1v1 格斗，不是 RPG。纯 IP 测试无法吸引格斗玩家 |
| 问答轮数 | **7 轮** | 5 轮（更短）/ 10 轮（更深） | 5 轮不够区分格斗风格；10 轮弃出率过高 |
| AI 语音 | **不做** | TTS 语音播报 | 增加开发复杂度 + 安全风险，第一阶段优先跑通核心漏斗 |
| 分享物数量 | **2 个（批命卡 + 报告）** | 只做报告 | 批命卡覆盖轻量传播场景，报告覆盖深度分享 |
| 格斗风格分类 | **12 种** | 6 种（太少）/ 20 种（太多） | 12 种覆盖主要格斗风格 + 一人之下角色映射 |
| 每日算命 | **不做，只预埋入口** | 本阶段上线 | 聚焦核心体检体验，每日算命是留存工具，放第二阶段 |
