## 二、推荐系统核心设计

### 2.1 推荐决策总框架

```
用户进入海克斯选择界面
      │
      ▼
┌─────────────────────────────────┐
│  Step 1: 打分（每个候选符文）     │
│  · 基础分 = 胜率映射的 S/A/B/C/D │
│  · 阶段修正（开局/7级/11级/15级）│
│  · 英雄适配修正                  │
│  · 组合联动加分                  │
│  = 最终推荐分                    │
└──────────┬──────────────────────┘
           ▼
┌─────────────────────────────────┐
│  Step 2: 排序与推荐              │
│  · 推荐分最高的为"首推"          │
│  · 其余两个给出一句话点评         │
│  · 生成刷新建议                  │
└──────────┬──────────────────────┘
           ▼
┌─────────────────────────────────┐
│  Step 3: 内容渲染                │
│  · 推荐卡片 + 推荐面板           │
│  · 标签 + 刷新建议               │
│  · 教练话术                      │
└─────────────────────────────────┘
```

### 2.2 推荐指数计算

#### 基础分（来自知识库预计算）

| 推荐指数 | 胜率区间 | 基础分 | 对新手的含义 |
|----------|----------|--------|------------|
| **S** | ≥ 60% | 100 | 碰到就拿，别犹豫 |
| **A** | 55%~60% | 80 | 很稳，选它不亏 |
| **B** | 52%~55% | 60 | 中规中矩，看情况 |
| **C** | 49%~52% | 40 | 一般般，考虑刷新 |
| **D** | < 49% | 20 | 不推荐，建议刷新 |

#### 阶段修正

| 选择阶段        | 修正规则                                 | 理由        |
| ----------- | ------------------------------------ | --------- |
| **开局 Lv.1** | 简单易懂 +10分；需配合 -10分；高阶玩法 -20分         | 开局推万金油    |
| **7级**      | 与已有符文可组黑科技 +25分；差1件凑套 +15分           | 开始考虑组合    |
| **11级**     | 与已有装备联动 +20分；补全build短板 +15分          | 基于build推荐 |
| **15级**     | 全部保守化，A级以上不鼓励刷新；D级符文 +5分（最后一次，总比没有强） | 最后机会不赌    |

#### 组合联动加分

| 场景 | 加分 | 条件 |
|------|------|------|
| 黑科技可成型 | +30 | 候选符文 + 已有符文/装备 = 已知黑科技组合 |
| 差1件激活套装 | +20 | 候选符文属于已有1个成员的套装 |
| 差2件激活套装 | +5 | 套装还远，微弱加分 |
| 同品质互斥 | -5 | 候选中有2个同套装的，选其一即可 |

### 2.3 刷新建议逻辑

```
if 三个中有 S 级:
    → 不建议刷新（"已经有天胡了，不建议刷新"）
elif 三个中最高 A 级 且 ≥2个 A/B 级:
    → 不建议刷新（"这批还行"）
elif 阶段 == 15级 且 有 ≥1个 A 级:
    → 不建议刷新（"最后一次了，稳一点"）
elif 三个中最高 B 级:
    → 可以刷新（"可以试试刷一下"）
elif 三个全 C/D:
    → 建议刷新（"这批比较弱，建议刷一下"）
    if 阶段 == 15级:
        → 仍可刷新但话术保守（"最后一次了，碰碰运气也行"）
```

## 三、推荐展示内容设计

### 3.1 推荐卡片信息架构

当用户面对三选一时，每张符文卡片上需要展示以下信息，**按视觉权重从高到低排列**：

```
┌──────────────────────────────────┐
│  [推荐指数角标 S/A/B/C/D]  [?]  │  ← L1: 一眼看到强度等级
│                                   │
│        ┌────────┐                 │
│        │ 符文图标│                 │  ← L2: 视觉识别
│        └────────┘                 │
│                                   │
│        符文名称                   │  ← L3: 知道是什么
│     [品质色 效果类型标签]         │  ← L4: 知道做什么
│                                   │
│   「AI人话描述」                  │  ← L5: 一句话说明效果
│   (≤25字，不含数值)               │
│                                   │
│  [⭐强力单卡] [🧪黑科技:XX]      │  ← L6: 功能标签（最多2个）
│  [🔗套装名 ①/④]                  │
│                                   │
│  刷新指数: XX%                    │  ← L7: 大众口碑参考
│       [🔄 刷新]                   │  ← L8: 刷新操作
└──────────────────────────────────┘
```

### 3.2 信息分层策略

| 层级 | 内容 | 展示方式 | 目的 |
|------|------|---------|------|
| **第一眼** | 推荐指数(S/A/B/C/D) + 符文名 | 常驻显示，角标+大字 | 0.5秒内判断值不值得选 |
| **第二眼** | AI人话描述 + 效果类型标签 | 常驻显示 | 3秒内理解这个符文做什么 |
| **第三眼** | 功能标签（强力/黑科技/套装） | 常驻小标签 | 5秒内了解额外价值 |
| **按需** | 二次解释（白话翻译+场景+联动） | 点击 ? icon 弹窗 | 深度理解复杂符文 |
| **按需** | 套装全貌/黑科技组合链路 | 点击标签弹窗 | 了解组合潜力 |

### 3.3 AI 教练推荐面板内容

```
┌─ 🤖 AI 教练推荐 ─────────────────────── [▲] ─┐
│                                                 │
│  💡 推荐选【{符文名}】— {推荐理由，≤30字}       │
│     "{教练详细点评，≤40字}"                     │
│                                                 │
│  · 【{次选1}】{一句话点评}                      │
│  · 【{次选2}】{一句话点评}                      │
│                                                 │
│  🔄 刷新建议: {建议文案}                        │
└─────────────────────────────────────────────────┘
```

### 3.4 各阶段教练话术差异化

#### 开局（Lv.1）— "简单直接，推万金油"

| 场景 | 教练话术 |
|------|---------|
| 出现 S 级 | "开局就天胡了！{符文名}碰到别犹豫直接拿！" |
| 最高 A 级 | "开局选{符文名}很稳，不需要配合任何装备就很强。" |
| 最高 B 级 | "这批中规中矩，{符文名}最适合你。不满意可以刷新碰运气。" |
| 全 C/D | "开局不急，三个都不强，大胆刷新碰碰运气。" |

#### 7级 — "开始组合联动"

| 场景 | 教练话术 |
|------|---------|
| 黑科技可成型 | "配上你开局拿的{已有符文}，{组合名}要成了！选{推荐符文}！" |
| 差1件凑套 | "你已经有一个{套装名}的符文了！再选这个就能激活套装效果。" |
| 普通推荐 | "{符文名}强度不错，配你这个英雄挺合适。" |

#### 11级 — "基于build推荐"

| 场景 | 教练话术 |
|------|---------|
| 与已有build联动 | "你有{已有符文A}+{已有符文B}，拿{推荐}直接三件套成型！" |
| 补短板 | "你全是输出没防御，{推荐}能让你多扛几下。" |
| 普通推荐 | "11级了，{推荐}能让你的build更完整。" |

#### 15级 — "保守策略，不赌"

| 场景 | 教练话术 |
|------|---------|
| 有 A 级以上 | "最后一次选择了，{推荐}很稳，不建议赌刷新。" |
| 最高 B 级 | "最后一次了，B级也能用，{推荐}选了不亏。" |
| 全 C/D | "最后一次了虽然都一般，{推荐}是里面最不亏的。碰碰运气也行。" |

## 四、个性化推荐策略

### 4.1 纯新手策略（首次接触大乱斗）

| 简化规则 | 说明 |
|----------|------|
| 只看推荐指数 | 直接推 S > A > B，不做复杂组合分析 |
| 屏蔽高阶符文 | 决策难度为"高阶玩法"的符文降低推荐权重 -20 |
| 话术更白 | "选它就完了" > "配合XX装备收益更大" |
| 默认不推套装 | 开局和7级不提凑套，避免增加认知负担 |
| 主动二次解释 | 特殊机制类符文自动展开白话解释 |

**新手首推万金油清单（高胜率 + 简单效果 + 通用）：**

| 符文 | 品质 | 胜率 | 为什么推给新手 |
|------|------|------|--------------|
| 巨人杀手 | 棱彩 | 62.3% | 变小加速增伤，选了就有效，不需配合 |
| 吸血习性 | 黄金 | 62.1% | 全能吸血，简单暴力，所有英雄通用 |
| 灵巧 | 白银 | 59.0% | 直接+60%攻速，不需理解任何机制 |
| 渴血 | 白银 | 59.0% | 15%全能吸血，效果直观回血明显 |
| 属性叠属性！ | 黄金 | 60.4% | 全面提升属性，完全不需要决策 |
| 歌利亚巨人 | 棱彩 | 56.6% | 体型变大+35%血量，坦克/前排必拿 |

### 4.2 回流用户策略（有基础但版本断档）

| 差异化规则 | 说明 |
|-----------|------|
| 标注新符文 | 上版本没有的符文显示"🆕新符文"角标 |
| 高亮套装机制 | 套装是新版本核心特性，主动介绍套装进度 |
| 推荐被低估符文 | 版本变化后很多符文强度变了，主动推荐宝藏符文 |
| UGC评论摘要 | 展示高赞评论帮助快速理解符文口碑 |
| 黑科技提示 | 回流用户有操作基础，可以推荐黑科技组合 |

**回流用户版本亮点推荐：**

| 符文 | 胜率 | 重点提示 |
|------|------|---------|
| 超凡邪恶 | 67.4% | "叠角龙套装核心，法师碰到无脑拿" |

### 4.3 休闲玩家策略（降低决策负担）

| 简化规则 | 说明 |
|----------|------|

| 不展示数据 | 不展示胜率数字和刷新指数，只用感受性描述 |
| 自动刷新提醒 | 全 C/D 时主动闪烁刷新按钮 + "这批弱，刷一下" |

## 五、边界情况处理

| 场景             | 处理策略                                       |
| -------------- | ------------------------------------------ |
| **全 D 级**      | 强烈建议刷新；话术："这批都不太行，大胆刷新碰运气！"；15级则推最不亏的      |
| **三个中两个同套装**   | 高亮"同属{套装名}"连线；如果套装价值高（叠角龙/神龙烈焰），推其一；否则推第三个 |
| **新符文无数据**     | 显示"🆕新符文"角标；回退全英雄平均胜率；冻结S/A评级，最高给B         |
| **符文与英雄类型不匹配** | 降权处理；话术加警告"这个符文不太适合你的英雄"；如近战英雄遇到射手专属符文     |
| **已有3个同套装差1件** | 最高优先级推荐；话术："满套了！白送一波超强增益！"                 |
| **黑科技冲突**      | S级 > 黑科技 > 套装 > A级，按固定优先级裁决                |

## 六、度量体系

### 6.1 核心指标

| 指标 | 定义 | 目标 | 衡量什么 |
|------|------|------|---------|
| **推荐采纳率** | 用户选择了推荐符文的比例 | > 60% | 推荐质量 |
| **符文选择胜率提升** | 实验组 vs 对照组的符文平均胜率差 | +3% | 决策质量 |
| **刷新采纳率** | 建议刷新时用户实际刷新的比例 | > 50% | 刷新建议质量 |
| **教练面板展开率** | 用户主动展开教练面板的比例 | > 70% | 产品吸引力 |
| **教练面板关闭率** | 用户关闭/永久折叠教练面板 | < 20% | 打扰程度 |

### 6.2 辅助指标

| 指标 | 定义 | 目标 |
|------|------|------|
| 标签点击率 | 黑科技/套装标签被点击查看的比例 | > 15% |
| 二次解释查看率 | ? icon 被点击的比例 | > 10% |
| 推荐响应速度 | 弹层打开到推荐展示的延迟 | < 500ms |
| 新手符文选择正确率 | 新手选择 S/A 级符文的比例变化 | +20% |
| 次日/7日留存提升 | 新手在教练引导下的留存变化 | +5% |

### 6.3 验证方案

```
Phase 1: 离线验证
  · 用历史对局数据回测推荐算法
  · 对比推荐符文 vs 用户实际选择 vs 最优选择的差距

Phase 2: A/B 测试
  · 实验组: 开启推荐系统
```

## 九、总结

### 回答你的两个核心问题

**Q1: 当用户面临选择的时候，该推荐给他什么？**

按优先级排序：
1. **有 S 级就推 S 级** — 巨人杀手/吸血习性/超凡邪恶这类天胡符文，碰到就拿
2. **有黑科技可成型就推黑科技** — 已有坦克引擎再出回城 = 不死坦克
3. **有套装差1件就推凑套** — 激活套装 = 白送一波增益
4. **推 A 级强力单卡** — 简单有效，不需配合
5. **推 B 级中适配最好的** — 看英雄类型匹配
6. **全弱则建议刷新** — 非15级时大胆刷新

**Q2: 具体需要展示哪些内容？**

| 信息 | 展示方式 | 理由 |
|------|---------|------|
| 推荐指数 S/A/B/C/D | 右上角彩色角标 | 0.5秒判断强弱 |
| AI人话描述 | 卡片内一句话 | 3秒理解效果 |
| 推荐 + 理由 | 教练面板首行 | 明确告知选什么 |
| 次选点评 | 教练面板次行 | 了解另外两个 |
| 功能标签（⭐/🧪/🔗） | 卡片内小标签 | 额外价值一目了然 |
| 刷新建议 | 刷新区域文案 | 要不要换一批 |
| 二次解释 | 点击?弹窗 | 复杂符文按需深入 |
| UGC口碑 | 刷新指数数值 | 大众选择参考 |

## 附录 A：Agent Teams 增量发现汇总

> 以下内容来自三个 Agent 团队成员（数据分析师、游戏设计师、产品设计师）的深度分析报告，作为主方案的补充参考。

### A.1 数据分析师关键发现

**品质与胜率的反直觉关系：**
- 黄金等级平均胜率最高（53.86%），棱彩反而最低（52.03%）
- **结论：棱彩≠强力，效果越极端条件越苛刻。** 新手不应盲目追棱彩

**D 级是常见场景，不是边界 case：**
- D 级占 52.2%（152/291），全 D 级三选一概率约 14.2%（每 7 次遇到一次）
- **结论：全 D 场景的教练话术需要 8-10 条变体库，避免重复；应列为 MVP P0 功能**

**新符文冷启动更乐观：**
- 44 个新符文平均胜率 53.73% > 总体 52.92%
- **结论：新符文冷启动默认评级从 B 调整为 B+，鼓励尝鲜，也符合运营推新目标**

**大众选择总体理性：**
- 选取率 Top10 平均胜率 60.2%，高选取率的符文确实强
- **结论：刷新指数（被刷新率）是可靠的参考信号**
