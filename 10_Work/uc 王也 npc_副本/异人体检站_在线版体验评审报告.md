## 一、整体体验 Review

### 1.1 体验流程打分

| 步骤 | 当前体验 | 评分 | 核心问题 |
|------|---------|------|---------|
| STEP 0 落地页 | 输入ID，有王也对白，动画精美 | ⭐⭐⭐⭐ | 缺价值主张，新用户不知道这是什么（已知问题） |
| STEP 1 批命 | 五行拆字 + 打字机效果 + 星级 | ⭐⭐½ | **五行结果感知弱**，不够"WOW"，是本次重点改进项 |
| STEP 2 问诊 | 7轮争议话题选择 + AI回复 | ⭐⭐⭐½ | **太长**，中间段节奏平淡，非IP粉Q3-Q5体验断裂 |
| STEP 3 报告 | 六维雷达 + 格斗画像 + 深度评语 | ⭐⭐⭐⭐½ | 优秀，叙事弧线感强，但缺排名对比（已知问题） |
| STEP 4 裂变 | 分享/保存/预约 | ⭐⭐⭐½ | CTA过多（4个），应精简为2主+1弱 |

### 1.2 六个体验断点

| # | 断点位置 | 严重度 | 说明 |
|---|---------|--------|------|
| 1 | **STEP 1 五行展示** | 🔴 | 五行拆字占了批命卡1/3面积，但用户看完的反应是"所以呢？"而非"哇！"。这是第一印象位，不能浪费 |
| 2 | **STEP 1→2 转化** | 🟡 | "保存批命卡"和"深度体检"并列CTA，用户可能在此分流离开。批命卡的五行结果不够有趣，进入深度体检的好奇心不足 |
| 3 | **STEP 2 第3-4轮** | 🟡 | 吕慈/端木瑛 和 老天师的话题背景信息量大，手机上阅读成本高，非IP粉容易在此放弃 |
| 4 | **STEP 2 第5轮** | 🟡 | "三十六贼"话题与第3-4轮在认知层面接近（都是"大局 vs 个体"），递进感不够 |
| 5 | **STEP 2 整体** | 🔴 | 7轮×(阅读背景+选择+看回复) ≈ 手机上2.5-3.5分钟，超过大多数H5营销活动的耐心阈值 |
| 6 | **STEP 2 中途退出** | 🔴 | 完成4-6轮退出=什么都没拿到（已有兜底方案但demo未实现） |

## 二、7轮问答深度诊断

### 2.1 实际时长估算

| 轮次 | 内容 | 阅读+选择时长 | 看AI回复 | 小计 |
|------|------|-------------|---------|------|
| Q1 陈朵·选择权 | 有storyContext背景板 | 20-30s | 8-12s | ~35s |
| Q2 陈朵·生死 | 有storyContext背景板 | 20-30s | 8-12s | ~35s |
| Q3 吕家·集体vs个体 | 有storyContext背景板 | 20-30s | 8-12s | ~35s |
| Q4 老天师·秩序 | 有storyContext背景板 | 20-30s | 8-12s | ~35s |
| Q5 三十六贼·道义 | 有storyContext背景板 | 20-30s | 8-12s | ~35s |
| Q6 张楚岚·底线 | 有storyContext背景板 | 15-25s | 8-12s | ~30s |
| Q7 终极之问 | 自由输入(打字) | 15-25s | 10-15s | ~30s |
| **合计** | | | | **3-4分钟** |

> **结论**：实际体验时长 3-4 分钟，超过 PRD 预估的 2 分钟。在手机碎片化场景下，这已接近用户耐心上限。

### 2.2 弃出风险热力图

```
Q1 ████░░░░░░ 低（开场新鲜感+陈朵故事有吸引力）
Q2 █████░░░░░ 低-中（连续两轮陈朵，节奏开始重复）
Q3 ███████░░░ 中-高（🔴 吕慈/端木瑛对非IP粉极不友好，背景信息最长）
Q4 ████████░░ 高（🔴 连续第4道重话题，认知疲劳明显）
Q5 ████████░░ 高（🔴 与Q3-Q4主题接近，用户觉得"又是类似的"）
Q6 ██████░░░░ 中（张楚岚相对更通俗）
Q7 █████░░░░░ 低-中（终极之问仪式感强，但前面已弃出的人看不到）
```

**关键发现**：**Q3-Q5 是弃出重灾区**，三轮连续的"大义vs小我"主题让用户产生认知疲劳。

### 2.3 内容重复性分析

| 主题 | 涉及轮次 | 重复度 |
|------|---------|--------|
| 保护vs控制/自由 | Q1 + Q3 | 🟡 有重叠 |
| 牺牲vs代价 | Q2 + Q5 | 🟡 有重叠 |
| 力量/手段vs正义 | Q4 + Q6 | 🟡 有重叠 |
| 自我认知 | Q7 | ✅ 独立 |

> **7轮中实际只有 4 个真正独立的维度**，其余是变体。这意味着缩减到 5 轮不会显著损失区分度。

### 2.4 非IP粉友好度

| 轮次 | 需要IP知识？ | 非IP粉体验 |
|------|------------|-----------|
| Q1 陈朵 | 需要了解陈朵和老廖 | 🟡 storyContext可帮助理解，但阅读量大 |
| Q2 陈朵续 | 需要了解张楚岚 | 🟡 同上 |
| Q3 吕慈 | 需要了解吕家和端木瑛 | 🔴 **最不友好**——复杂的人物关系链 |
| Q4 老天师 | 需要了解甲申之乱 | 🔴 **不友好**——专有历史事件 |
| Q5 三十六贼 | 需要了解无根生和三十六贼 | 🔴 **极不友好**——最深的lore |
| Q6 张楚岚 | 相对通用 | 🟡 手段vs目的是通用主题 |
| Q7 终极 | 不需要 | ✅ 完全通用 |

> **Q3-Q5 对非IP粉构成"三连墙"**——连续三轮需要大量IP背景知识，是弃出的主因。

## 三、缩减方案：7轮 → 5轮

### 3.1 推荐方案：「3+1+1」结构

```
┌─────────────────────────────────────────────────────┐
│                   5轮问诊（约2分钟）                    │
│                                                      │
│  Q1 ⚡ 破冰·测应激反应            [浅·IP友好]         │
│     改编自原Q1陈朵，但去掉IP专属包袱                     │
│     → "你在路上看到有人被围攻，对方明显比你强。你会？"     │
│                                                      │
│  Q2 ⚔️ 格斗·测战斗风格            [中·贴游戏]         │
│     新增！原7轮中缺少直接的格斗风格测试                    │
│     → "擂台上对手比你壮两圈，开局怎么打？"               │
│                                                      │
│  Q3 ⚖️ 灰度·测道德观              [深·有争议]         │
│     合并原Q3(吕慈)+Q4(老天师)的核心冲突                  │
│     → "你的师兄为了保护家人叛变了。擂台上你们相遇，怎么打？"│
│                                                      │
│  Q4 🌌 底色·测孤独观              [深·情感]           │
│     保留原Q6张楚岚的核心                                │
│     → "格斗是一个人的事。你更怕一个人上场，还是所有人看着？"│
│                                                      │
│  Q5 💫 终极之问                    [核心·开放]         │
│     保留原Q7                                          │
│     → "最后，三个字评价自己。"                          │
│                                                      │
└─────────────────────────────────────────────────────┘
```

### 3.2 保留/删除理由

| 原轮次 | 处理 | 理由 |
|--------|------|------|
| Q1 陈朵·选择权 | ✂️ **改写为通用版** | 保留"应激反应"测试维度，但去掉陈朵/老廖的IP包袱 |
| Q2 陈朵·生死 | ❌ **删除** | 与Q1主题重复（都是陈朵线），且生死观在营销活动中太沉重 |
| Q3 吕慈·集体 | ✂️ **合并入新Q3** | 核心冲突"忠义vs背叛"提炼为更通用的表述 |
| Q4 老天师·秩序 | ❌ **删除** | 需要甲申之乱背景，非IP粉最大障碍，且与Q3/Q6主题重叠 |
| Q5 三十六贼·道义 | ❌ **删除** | 最深的IP lore，对非IP粉极不友好，且"追求vs代价"被Q7覆盖 |
| Q6 张楚岚·底线 | ✂️ **简化为新Q4** | 核心冲突好，但从"张楚岚的手段"改写为更通用的格斗孤独感 |
| Q7 终极之问 | ✅ **保留** | 仪式感强，是报告生成的关键锚点 |
| **新增** | ⚡ **新增Q2格斗题** | 原7轮中竟然没有直接的格斗风格测试！这是格斗游戏的核心 |

### 3.3 5轮的维度覆盖

| 维度 | 对应轮次 | 映射到报告 |
|------|---------|-----------|
| 应激反应（战/逃） | Q1 | 攻击力 + 反应速 |
| 格斗风格（压制/反击/灵活） | Q2 | 攻击力 + 防御力 + 读招力 |
| 道德灰度（忠义/冷血） | Q3 | 读招力 + 反应速 |
| 性格底色（内向/外向 × 抗压） | Q4 | 抗压值 + 摸鱼值 |
| 自我认知 | Q5 | 综合校准 + 一致性分析 |

> **5轮覆盖了六维属性所需的全部输入**，区分度不会明显下降。

### 3.4 弹性设计（可选）

如果担心5轮信息不够：
- 在Q5结束后加一个**"加深按钮"**：*"王也觉得还没看透你。再聊两句？"*
- 选择加深→额外2轮深度IP话题（原Q3吕慈+Q5三十六贼的简化版）
- 选择跳过→直接出报告
- 加深后的报告标记为"完整版"，增加社交对比

### 3.5 时长预估

| 轮次 | 时长 |
|------|------|
| Q1 通用破冰 | 15-20s（无需阅读长背景）|
| Q2 格斗风格 | 15-20s（直觉题，快速选择）|
| Q3 道德灰度 | 20-25s（有一定背景但简化）|
| Q4 孤独观 | 15-20s（情感题，快速反应）|
| Q5 终极 | 15-25s（自由输入）|
| **合计** | **80-110秒 ≈ 1.5-2分钟** ✅ |

## 四、ID五行方案需求评审

### 4.1 当前五行方案的问题

#### 保留的优点
- ✅ **确定性**：同一ID每次结果一致，支持缓存/预生成
- ✅ **有文化底蕴**：五行是道教元素，与王也人设有天然关联
- ✅ **拆字展示有仪式感**：逐字标注五行、占比条形图，视觉效果不错

#### 系统性缺陷

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| 1 | **结果感知弱** | 🔴 | "你的ID主属金"——用户反应是"然后呢？"而不是"哇！"。五行对Z世代缺乏直觉认知 |
| 2 | **映射逻辑牵强** | 🔴 | 英文字母A-E→木、F-J→火……完全是人为编排，稍有思考就知道"假的"。Unicode编码取模更是纯随机 |
| 3 | **区分度极低** | 🔴 | 只有5种主五行，20%的用户拿到完全相同的主属性标签。加上辅属性也才 5×4=20 种组合 |
| 4 | **与IP核心脱节** | 🟡 | 《一人之下》的核心标签是"炁"、"门派"、"异能"、"十佬"，不是"五行"。五行在作品中是底层概念但非前台标签 |
| 5 | **浪费第一印象位** | 🔴 | 批命卡是用户看到的第一个AI输出，应该用来制造"王也读懂了我"的惊喜感，而不是展示一个五行占比条 |
| 6 | **LLM评语与五行割裂** | 🟡 | 当前逻辑是：先算五行→把五行结果喂给LLM→LLM生成评语。但LLM的评语质量才是核心，五行分析反而成了噪音 |

#### 结论
> **五行拆字应该降级为"后台计算参数"，不再作为前台展示的核心。** 保留其确定性计算能力（用于稳定星级和标签），但用户看到的应该是更有IP感、更有趣的结果呈现。

### 4.2 替代方案比较

#### 方案A：「炁脉鉴定」（推荐 ✅）

| 维度 | 说明 |
|------|------|
| **一句话** | 把五行映射升级为"炁脉属性"映射，用《一人之下》的世界观包装 |
| **输入** | 用户ID/网名（不变） |
| **分析逻辑** | ① 确定性计算：基于ID字符hash→映射到6种炁脉属性（非五行）② LLM生成评语 |
| **用户看到** | 「炁脉属性：风后奇门」+「异人直觉 ★★★★」+「潜力评级：甲等·破格」+ 王也评语 |
| **优势** | IP感极强（炁/门派是核心标签）、区分度高（6炁脉×12门派×4评级=288种）、保留确定性 |
| **劣势** | 需要重新设计映射表，前端UI重做 |
| **IP关联** | 🔴 高 |
| **技术复杂度** | 🟡 中（映射表改写，UI改写，LLM Prompt调整） |
| **WOW感** | 🔴 高（"王也看穿了我的炁脉属性"比"我的ID属金"有趣太多） |

#### 方案B：「纯LLM读名」

| 维度 | 说明 |
|------|------|
| **一句话** | 完全放弃确定性计算，让LLM直接分析名字含义并生成所有结果 |
| **输入** | 用户ID/网名 |
| **分析逻辑** | 纯LLM：一次调用生成评语+标签+星级 |
| **用户看到** | 纯AI评语 + 3个标签 + 异人潜质星级 |
| **优势** | 最灵活，每个人的结果都独一无二 |
| **劣势** | ❌ 不确定性高（同一ID两次输入结果不同），无法预生成/缓存，时延增加 |
| **IP关联** | 🟡 中（取决于Prompt质量） |
| **技术复杂度** | 🟢 低 |
| **WOW感** | 🟡 中-高（但不稳定） |

#### 方案C：「异人档案匹配」

| 维度 | 说明 |
|------|------|
| **一句话** | 基于ID特征匹配到最像的《一人之下》角色，走"你最像谁"路线 |
| **输入** | 用户ID/网名 |
| **分析逻辑** | ID hash→映射到20+角色池中的一个角色 + LLM生成评语 |
| **用户看到** | 「你最像：张楚岚」+ 角色卡 + 王也吐槽 |
| **优势** | IP感最强，"我是哪个角色"社交分享价值最高 |
| **劣势** | ❌ 区分度问题（只有20+角色），与后续体检报告的"门派归属"重复 |
| **IP关联** | 🔴 高 |
| **技术复杂度** | 🟢 低 |
| **WOW感** | 🟡 中（人格测试的老套路） |

#### 方案D：「改良五行」（保守方案）

| 维度 | 说明 |
|------|------|
| **一句话** | 保留五行计算，但用IP世界观重新包装展示 |
| **输入** | 用户ID/网名 |
| **分析逻辑** | 现有五行计算不变，但展示改为"炁"相关表述 |
| **用户看到** | 「炁属·风」（替代"主属金"）+ 王也评语 |
| **优势** | 改动最小 |
| **劣势** | ❌ 换皮不换骨——核心问题（区分度低、映射牵强）未解决 |
| **IP关联** | 🟡 中 |
| **技术复杂度** | 🟢 低 |
| **WOW感** | 🟡 中（稍有提升但有限） |

### 4.3 推荐方案：「炁脉鉴定」（方案A）详细设计

#### 4.3.1 炁脉属性体系（替代五行）

| 炁脉属性 | 对应关键词 | IP关联 | 颜色 |
|---------|-----------|--------|------|
| **风后奇门** | 洞察、控制、大局观 | 王也的看家本事 | 青/翠 |
| **炁体源流** | 天赋、潜力、不可预测 | 冯宝宝/张楚岚 | 金/白 |
| **通明拳意** | 刚猛、正道、不退让 | 张灵玉/陆瑾 | 红/赤 |
| **双全之手** | 治愈、牺牲、两面性 | 端木瑛/陈朵 | 紫/靛 |
| **性命双修** | 隐忍、爆发、后劲 | 张楚岚/诸葛青 | 橙/琥珀 |
| **天师雷法** | 权威、秩序、碾压 | 张之维/天师府 | 蓝/靛 |

> 6种炁脉 vs 5种五行 → 区分度提升20%。更重要的是每种炁脉都有明确的IP角色映射，用户立刻能产生情感连接。

#### 4.3.2 映射逻辑（确定性+LLM混合）

```
确定性部分（保证同一ID结果稳定）：
┌──────────────┐
│  用户输入 ID   │
│  "炼狱修罗杀神" │
└──────┬───────┘
       ▼
┌──────────────────────────┐
│ Step 1: 字符分析（改良版）   │
│ - 中文字：偏旁/含义 → 6维映射│
│ - 英文字母：音韵学分组         │
│ - 数字：天干地支（保留）       │
│ - 结果：6维向量 [风后, 炁体,  │
│   通明, 双全, 性命, 天师]     │
└──────┬───────────────────┘
       ▼
┌──────────────────────────┐
│ Step 2: 主属性判定           │
│ - 最高维度 = 主炁脉           │
│ - 次高维度 = 暗合属性         │
│ - 综合分 = 潜力评级           │
│   (甲等·破格/乙等·上品/      │
│    丙等·良才/丁等·待觉醒)     │
└──────┬───────────────────┘
       ▼
┌──────────────────────────┐
│ Step 3: 标签生成             │
│ - 炁脉标签：「风后奇门·洞察」  │
│ - 角色标签：「暗合王也」       │
│ - 战斗标签：「后发先至型」     │
│ - (2-3个标签，hash确定性选择) │
```
