## 一、核心漏斗事件（P0 — 上线前必须完成）

> 这些事件构成完整用户漏斗，是 KPI 追踪和 Go/No-Go 决策的数据基础。

### 1. 落地页 → 输入 ID

| 事件名 | 触发时机 | 属性 | 类型 | 说明 |
|--------|---------|------|------|------|
| `page_view` | 落地页加载完成 | `source`(direct/share_link/kol), `utm_campaign`, `utm_medium`, `utm_source`, `referrer`, `platform`(h5/webview), `device_type`(ios/android), `share_from_session_id` | 曝光 | 漏斗顶部 |
| `landing_scroll` | 落地页向下滚动 >50% | `scroll_depth`(50/75/100) | 行为 | 衡量价值主张阅读率 |
| `id_input_focus` | 用户点击 ID 输入框 | — | 行为 | 输入意向 |
| `id_input_submit` | 用户提交 ID | `input_id`(脱敏哈希), `input_length`, `has_special_char` | 转化 | 漏斗关键节点 |
| `id_input_error` | ID 输入校验失败 | `error_type`(empty/too_long/blocked/审核拦截) | 异常 | 监控输入异常 |

### 2. STEP 1 批命

| 事件名 | 触发时机 | 属性 | 类型 | 说明 |
|--------|---------|------|------|------|
| `fortune_request` | 批命请求发出 | `session_id` | 请求 | — |
| `fortune_queued` | 进入排队 | `session_id`, `queue_position`, `estimated_wait` | 排队 | 监控排队体验 |
| `fortune_queue_abandon` | 排队中用户离开 | `session_id`, `wait_duration_ms`, `queue_position` | 流失 | 排队弃出率 |
| `fortune_loading_start` | 叙事化等待动画开始 | `session_id`, `hit_source`(exact/fuzzy/realtime) | 体验 | 等待体验 |
| `fortune_result` | 批命结果展示 | `session_id`, `hit_source`, `element`(五行), `fortune_score`, `latency_ms` | 转化 | 漏斗关键节点 |
| `fortune_error` | 批命请求失败 | `session_id`, `error_code`, `error_message` | 异常 | 监控可用性 |

### 3. 批命卡交互

| 事件名 | 触发时机 | 属性 | 类型 | 说明 |

| `card_share_success` | 分享成功回调 | `session_id`, `share_channel` | 转化 | 实际分享率 |

### 4. STEP 2 七轮问诊

| 事件名 | 触发时机 | 属性 | 类型 | 说明 |

| `chat_round_answer` | 用户每轮回答提交 | `chat_id`, `round`, `answer_type`(option/text), `option_id`, `text_length`, `think_duration_ms` | 行为 | 逐轮参与度 |

| `chat_sse_error` | SSE 连接断开/错误 | `chat_id`, `round`, `error_type`(timeout/disconnect/server_error), `reconnect_count` | 异常 | SSE 稳定性 |
| `chat_abandon` | 用户中途退出 | `chat_id`, `last_round`, `stay_duration_ms`, `total_rounds_completed` | 流失 | 🔴 **弃出率核心指标**（逐轮） |

## 四、核心看板指标定义

### 实时看板（首日 24h 值班用）

| 指标名 | 计算公式 | 告警阈值 | 刷新频率 |
|--------|---------|---------|---------|
| **QPM** | COUNT(page_view) per minute | > 50K → 排队 | 10s |
| **错误率** | COUNT(fortune_error + chat_sse_error + report_error) / COUNT(所有请求) | > 1% → 🔴 | 10s |
| **非负评率** | 1 - COUNT(safety_block WHERE action=block) / COUNT(所有 AI 输出) | < 93% → 🔴 熔断 | 1min |
| **P99 延迟** | P99(perf_sse_latency.first_token_ms) | > 5s → 🟡 | 1min |
| **离线命中率** | COUNT(offline_hit) / COUNT(fortune_request) | < 50% → 🔴 | 5min |
| **渲染降级率** | COUNT(render_fallback) / COUNT(report_ready) | > 10% → 🟡 | 5min |

### 业务看板（日报/周报用）

| 指标名 | 计算公式 | 目标（基准档） |
|--------|---------|-------------|
| **DAU** | COUNT(DISTINCT user_id WHERE page_view) | — |
| **输入 ID 数** | COUNT(id_input_submit) | 200 万 |
| **浅→深转化率** | COUNT(card_deep_check_click) / COUNT(card_view) | ≥ 55% |
| **体检完成率** | COUNT(chat_complete) / COUNT(chat_start) | ≥ 75% |
| **逐轮弃出率** | COUNT(chat_abandon WHERE last_round=N) / COUNT(chat_round_view WHERE round=N) | — |
| **Q5 弃出率** | COUNT(chat_abandon WHERE last_round=5) / COUNT(chat_round_view WHERE round=5) | 重点监控 |
| **分享率** | COUNT(card_share_success + report_share_success) / COUNT(card_view + report_ready) | ≥ 22% |
| **K-factor** | (分享次数 × 每次分享带来的 share_link_open) / DAU | ≥ 1.0 |
| **新增预约** | COUNT(reservation_success WHERE is_new_reservation=true) | 60 万 |
| **保存率** | COUNT(card_save + report_save) / COUNT(card_view + report_ready) | — |

### 隐私合规

- ❌ **不采集**: 真实姓名、手机号、IP 地址、精确位置
- ✅ **脱敏处理**: `input_id` 取哈希值，不存储明文
- ✅ **用户标识**: 使用微信 openid 或设备指纹，不关联个人信息
- ✅ **告知同意**: 落地页底部提供隐私政策链接
