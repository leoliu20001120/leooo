# 掌上英雄联盟 - 海克斯大乱斗接口分析文档

## 一、概述

掌上英雄联盟（掌盟）APP是腾讯官方LOL移动端应用，提供了海克斯大乱斗（ARAM）的符文数据、排行榜、UGC评分和评论等内容。本文档分析其核心接口，帮助开发者获取符文知识库所需数据。

## 二、抓包工具使用方法

### 2.1 推荐工具

| 工具 | 适用平台 | 说明 |
|------|---------|------|
| **Charles** | Windows/Mac | 推荐，支持HTTPS抓包，界面友好 |
| **Fiddler** | Windows | 微软系工具，功能强大 |
| **mitmproxy** | 全平台 | 命令行工具，可编程 |
| **Stream** | iOS | 手机端直接抓包 |
| **HttpCanary** | Android | 安卓端抓包工具 |

### 2.2 Charles 抓包步骤

#### 第1步：安装SSL证书（HTTPS抓包必须）

1. 打开 Charles → Help → SSL Proxying → Install Charles Root Certificate
2. 手机设置WiFi代理指向电脑IP + Charles端口（默认8888）
3. 手机浏览器访问 `chls.pro/ssl` 下载并安装证书
4. **iOS**：设置 → 通用 → 关于本机 → 证书信任设置 → 启用Charles证书
5. **Android**：设置 → 安全 → 从存储设备安装证书

#### 第2步：配置SSL Proxy

1. Charles → Proxy → SSL Proxying Settings
2. 勾选 "Enable SSL Proxying"
3. 添加 Host: `*` Port: `443`（抓取所有HTTPS请求）

#### 第3步：打开掌盟APP并抓包

1. 确保手机代理已指向Charles
2. 打开掌上英雄联盟APP
3. 进入：资料库 → 乱斗符文 / 海克斯大乱斗排行榜
4. 在Charles中过滤关键域名（见下文接口列表）

### 2.3 关键过滤域名

```
game.gtimg.cn
lol.qq.com
comm.ams.game.qq.com
apps.game.qq.com
mlol.qt.qq.com
ssl.zc.qq.com
```

### 3.1 ✅ 评论/评分接口（已确认可用）

#### 接口：符文评论列表

**请求地址**：
```
POST https://mlol.qt.qq.com/go/comment_svr/comment/list?plat=ios&version=10000
```

**请求方式**：POST

**域名**：`mlol.qt.qq.com`

**请求头**：
```http
Host: mlol.qt.qq.com
Accept: */*
Content-Type: application/json
User-Agent: QTL/12.4.1 (iPhone; IOS 18.6.2; Scale/3.00)
Accept-Language: zh-CN,zh-Hans;q=0.9
Accept-Encoding: gzip, deflate, br
Connection: keep-alive
GH-HEADER: 1-2-105-1241-0
Cookie: openid=xxx; access_token=xxx; appid=wx5a4a8ac0fd48303a; userId=xxx; clientType=10; accountType=2
```

**请求体（JSON）**：
```json
{
  "app_id": 1,
  "topic_id": "hexaramdatarune_1346",
  "top_comment_list": [
    {
      "comment_id": "",
      "reply_id_list": [""]
    }
  ],
  "start_time": "1773828873",
  "game_zone": "lol",
  "source_game_zone": "lol",
```

| 参数 | 类型 | 说明 |
|------|------|------|

| start_time | string | Unix时间戳（用于分页） |
| game_zone | string | 固定 "lol" |
| list_key | string | "new*" 表示最新评论 |

### 3.2 符文列表页面（WebView，非JSON接口）

#### 资料库 - 乱斗符文

**页面URL**：
```
https://lol.qq.com/zmlolzonehmtest/page/gamedata/?tab=ldbuff
```

> ⚠️ **注意**：这是一个WebView内嵌网页，符文列表数据**直接渲染在HTML中**，不通过独立的JSON接口获取！因此在Stream抓包中看不到符文列表的JSON请求。

#### 符文排行/详情页面

**URL格式**：
```
https://lol.qq.com/zmlolzonehm/page/runeMelee/?tabkey=buffRanking&id={符文编号}&open_comment=1
```

**示例**：
```
https://lol.qq.com/zmlolzonehm/page/runeMelee/?tabkey=buffRanking&id=1346&open_comment=1
```

### 3.3 符文图标资源

**域名**：`mlol-75948.qpic.cn`

**URL格式**：
```
https://mlol-75948.qpic.cn/common/{hash}/0
```

**示例（吸血习性图标）**：
```
https://mlol-75948.qpic.cn/common/00060fc07de544b628e9924977c9cb4e/0
```

### 3.4 topic_id 命名规则

所有乱斗符文的 topic_id 格式统一为：
```
hexaramdatarune_{编号}
```

已确认的编号：
- `1346` → 吸血习性（黄金级）

编号规则推测：1301-1400+ 依次编号，白银级靠前，黄金级中间，棱彩级靠后。

### 4.2 认证信息

评论接口**可能不需要**Cookie认证（需验证），但如需认证，关键字段：
```
openid=xxx
access_token=xxx
appid=wx5a4a8ac0fd48303a
userId=xxx
clientType=10
accountType=2
```

### 4.3 反爬策略

- `Svr-Ret-Code: 0` 表示请求成功
- 建议请求间隔 2-5 秒
- 使用掌盟APP的User-Agent: `QTL/12.4.1 (iPhone; IOS 18.6.2; Scale/3.00)`
