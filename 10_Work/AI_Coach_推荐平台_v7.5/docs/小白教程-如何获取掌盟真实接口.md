## 📱 选择B详细教程：抓包掌上英雄联盟

### 第1步：准备工具（约5分钟）

你需要：
- ✅ 一台电脑（你已经有了）
- ✅ 一部手机（装了掌上英雄联盟APP）
- ✅ 电脑和手机连同一个WiFi

然后下载一个抓包工具，推荐用 **Fiddler**（因为你是Windows）：

1. 打开浏览器，搜索 `Fiddler Classic 下载` 或访问：https://www.telerik.com/download/fiddler
2. 下载并安装 Fiddler Classic（免费的）
3. 安装完打开它

### 第2步：配置Fiddler（约10分钟）

#### 2.1 开启HTTPS抓包
因为掌盟的接口都是HTTPS加密的，需要先开启解密：

1. 打开Fiddler
2. 点击顶部菜单 `Tools` → `Options`
3. 点击 `HTTPS` 标签页
4. 勾选 ✅ `Capture HTTPS CONNECTs`
5. 勾选 ✅ `Decrypt HTTPS traffic`
6. 弹出提示框问你要不要安装证书，全部点 `Yes`
7. 点 `OK` 保存

#### 2.2 开启远程连接（让手机能连到Fiddler）
1. 还是在 `Tools` → `Options`
2. 点击 `Connections` 标签页
3. 勾选 ✅ `Allow remote computers to connect`
4. 记住这里的端口号，默认是 `8888`
5. 点 `OK`，Fiddler会提示重启，重启它

#### 2.3 查看你电脑的IP地址
1. 按 `Win + R`，输入 `cmd`，回车
2. 输入 `ipconfig`，回车
3. 找到你连WiFi的那个网卡（通常是 `无线局域网适配器 WLAN`）
4. 记下 `IPv4 地址`，比如 `192.168.1.100`

### 第3步：手机连接Fiddler（约5分钟）

#### 3.1 设置手机WiFi代理

**如果是iPhone：**
1. 设置 → 无线局域网 → 点你连的WiFi名称右边的 `ⓘ`
2. 滚到最下面，点 `配置代理` → `手动`
3. 服务器填：你电脑的IP（比如 `192.168.1.100`）
4. 端口填：`8888`
5. 点 `存储`

**如果是安卓：**
1. 设置 → WLAN → 长按你连的WiFi → `修改网络`
2. 展开 `高级选项`
3. 代理选 `手动`
4. 主机名填：你电脑的IP
5. 端口填：`8888`
6. 保存

#### 3.2 安装证书（HTTPS必须！）

1. 手机浏览器打开：`http://你电脑的IP:8888`
   - 比如 `http://192.168.1.100:8888`
2. 页面上会显示 `FiddlerRoot certificate`，点击它下载证书

**iPhone额外步骤：**
3. 设置 → 通用 → VPN与设备管理 → 找到 `DO_NOT_TRUST_FiddlerRoot` → 安装
4. 设置 → 通用 → 关于本机 → 滚到最下面 → 证书信任设置 → 打开 Fiddler 的开关

**安卓额外步骤：**
3. 设置 → 安全 → 从存储设备安装证书 → 找到下载的证书安装

这一步是最关键的，请**严格按顺序操作**：

## 🆘 常见问题

### Q1: Fiddler里一堆请求，眼花了怎么办？
在Fiddler底部的命令栏里输入过滤：
```
=game.gtimg.cn OR =lol.qq.com OR =qq.com
```
这样只显示腾讯域名的请求。

### Q2: 手机连了代理后打不开网页？
- 检查电脑防火墙有没有放行Fiddler（8888端口）
- 试试暂时关闭Windows防火墙
- 确认电脑和手机在同一个WiFi

### Q3: HTTPS请求显示为灰色/tunnel？
证书没装好。重新执行第3步的证书安装步骤，**特别注意iPhone要去信任设置里手动开启**。

### Q4: 掌盟打开后Fiddler里没有请求？
- 确认手机代理设置正确（IP和端口）
- 试试在手机浏览器打开 `http://你的电脑IP:8888`，看能不能打开Fiddler页面
- 如果打不开，说明代理没连通

### Q5: 我不想装Fiddler，有更简单的方法吗？
如果你是iPhone，可以用 **Stream** APP（App Store搜索"Stream"，选"Network Debug Tool"那个），它可以直接在手机上抓包，不需要电脑。操作更简单：
1. 安装Stream → 点击"开始抓包"
2. 安装VPN配置（Stream通过VPN方式抓包）
3. 打开掌盟浏览符文页面
4. 回到Stream查看抓到的请求

### Q6: 我实在搞不定抓包怎么办？
**完全没问题！** 目前的知识库数据已经够用了，核心的符文名称、等级、Tier分级、胜率、选取率、适配英雄这些关键数据全都有。缺失的icon可以后续慢慢补充。
