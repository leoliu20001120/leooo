二评分函数设计

2.1 核心公式

最终得分 = 基础分 × 连胜连败系数 + 黑科技组合加成（含阶段系数）
💡 关键修正：阶段系数不再是独立的乘法因子，而是和黑科技组合加成绑在一起的。
• 通用黑科技组合：只有S1/S2阶段才给黑科技加成（还有机会凑第二张）
• 英雄专属黑科技：不受阶段限制，S1-S4都给加成（单卡即生效）
• 不再有独立的"阶段系数"乘法因子

2.2 基础分计算（0-100分）

# 基础分 = 三维度加权
基础分 = (
    符文胜率分 × W_winrate      # 数据源：hextech_augments.json win_rate（全局胜率）
  + 符文选择率分 × W_pickrate   # 数据源：hextech_augments.json pick_rate（全局选择率）
  + UGC评分分 × W_ugc          # 数据源：zhangmeng_ugc.json score (10分制)
)
💡 简化说明：基础分只保留3个维度。"符文胜率"就是该英雄选这个符文的胜率，胜率本身已隐含了英雄适配信息，越简单越好，方便后续调参。

各维度归一化方法

维度数据源归一化公式说明
符文胜率分hextech_augments.win_rate（全局）(wr - 45) / 25 × 10045%→0分, 70%→100分
符文选择率分hextech_augments.pick_rate（全局）min(pr / 3.0, 1.0) × 100选取率反映社区共识
UGC评分分zhangmeng_ugc.score (10分制)score / 10 × 100无评分则默认50
💡 归一化公式设计依据（基于实际数据范围）：
• 胜率 (wr-45)/25×100：全局胜率范围约43.93%~67.39%，45%作下界→0分，70%作上界→100分
• 选择率 min(pr/3.0,1.0)×100：全局选择率范围约0%~2.08%，3%作饱和点
• MVP版本使用全局胜率/选择率，暂不按阶段拆分（阶段样本量差异大）

2.3 黑科技组合加成 + 标签判定（v2.8）

💡 v2.8核心修正：专属黑科技+20，组合成型+适配+20，S1/S2潜在组合+5，S3/S4适配未成型+5，不适配+3，上限20。阈值按符文等级分层。
def 判定黑科技标签和加成(当前符文, 已选符文列表, 当前阶段, 当前英雄):
    """返回: (加成分, 标签, 话术) ★ v2.8: 上限20"""
    加成, 标签, 话术 = 0, None, ""

    # ═══ 一、英雄专属黑科技（不受阶段限制，+20） ═══
    if (当前英雄, 当前符文) in 英雄专属黑科技库:
        加成 += 20   # 专属黑科技+20
        标签 = "黑科技"

    # ═══ 二、通用黑科技组合（阶段系数在这里体现） ═══
    for 组合 in 通用黑科技组合库:
        if 当前符文 not in [组合.aug1, 组合.aug2]: continue

        适配 = 组合适配英雄(组合, 当前英雄)
        另一半 = 组合.aug2 if 当前符文 == 组合.aug1 else 组合.aug1
        已有另一半 = 另一半 in 已选符文列表

        if 已有另一半 and 适配:
            加成 += 20  # 组合成型 + 适配英雄：+20
            标签 = "黑科技"
        elif 已有另一半 and not 适配:
            加成 += 3   # 组合成型但不适配英雄 → +3
        elif 当前阶段 <= 2 and 适配:
            加成 += 5   # ★ S1/S2 + 适配英雄 → 潜在组合+5
            if 标签 != "黑科技": 标签 = "黑科技"
        elif 当前阶段 > 2 and 适配:
            加成 += 5   # S3/S4 + 适配但没有另一半 → +5，不标黑科技
        # ★ 不适配英雄 + 未成型 → 直接跳过，不加分

    # ═══ 三、套装羁绊加成 ═══
    for 套装 in 官方9个套装:
        if 套装内已有 >= 2: 加成 += 3 * 套装内已有

    return min(加成, 20), 标签, 话术

三黑科技组合标签体系（v2.0 — 2符文核心）

3.1 核心定义

黑科技组合 = 2个符文形成机制协同

  1. 机制协同：A增强B 或 A+B 产生 1+1 > 2 效果
  2. 数据验证：champion_combos 多英雄使用 / 社区"黑科技/神级"标签
  3. 推荐话术 ≤ 10字：如"双灼烧叠加"、"叠血变大"
  4. 不排除套装内组合：有独立机制协同即可
