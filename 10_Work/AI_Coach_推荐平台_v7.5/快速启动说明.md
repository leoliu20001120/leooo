# AI Coach 符文推荐平台 v7.5 - 快速启动

## 环境要求
- Python 3.8+

## 使用步骤

### 1. 解压项目文件

### 2. 安装依赖
```bash
pip install flask requests beautifulsoup4 pandas openpyxl lxml python-docx numpy
```

或使用 requirements.txt：
```bash
pip install -r requirements.txt
```

### 3. 启动服务
```bash
python app.py
```

### 4. 打开页面
浏览器访问: http://127.0.0.1:5000/
