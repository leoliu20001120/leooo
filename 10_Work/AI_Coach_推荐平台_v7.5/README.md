# 海克斯大乱斗符文知识库

> 为海克斯大乱斗AI Coach构建的符文知识库生成工具，支持多数据源爬取、AI内容生成和Excel知识库输出。

## 📁 项目结构

```
├── main.py                     # 主入口，串联完整流水线
├── config.py                   # 全局配置（API地址、请求头、阈值等）
├── requirements.txt            # Python依赖
├── README.md                   # 本文档
├── docs/
│   └── 掌盟接口分析文档.md      # 掌上英雄联盟APP接口抓包教程
├── crawlers/                   # 爬虫模块
│   ├── base_crawler.py         # 爬虫基类（请求/重试/延迟）
│   ├── hextech_crawler.py      # hextech.dtodo.cn 符文数据爬虫
│   ├── zhangmeng_crawler.py    # 掌上英雄联盟 符文+UGC爬虫
│   └── bilibili_crawler.py     # B站 符文攻略内容爬虫
├── processors/                 # 数据处理模块
│   ├── data_merger.py          # 多源数据合并器
│   ├── ai_content_generator.py # AI内容生成器（人话描述/推荐理由/冷知识）
│   └── recommendation_calculator.py # 推荐指数计算器
├── generators/
│   └── excel_generator.py      # Excel知识库生成器（7个Sheet）
└── output/
    ├── raw/                    # 爬取原始数据（JSON）
    └── 海克斯大乱斗符文知识库.xlsx  # 最终输出
```

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行完整流水线

```bash
python main.py
```

### 3. 命令行参数

```bash
# 跳过爬取阶段，使用已有数据直接生成Excel
python main.py --skip-crawl

# 指定输出路径
python main.py --output ./my_output/knowledge.xlsx

# 只运行爬虫，不生成Excel
python main.py --only-crawl
```

## 📊 知识库Excel结构（7个Sheet）

| Sheet | 名称 | 内容说明 |
|-------|------|---------|
| 1 | **符文基础信息** | 核心表：名称、等级、Tier、推荐指数(S/A/B/C/D)、胜率、选取率、官方描述、人话描述、UGC评分等 |

| 5 | **符文套装系统** | 官方套装：套装名称、效果、组成符文 |
| 6 | **符文冷知识** | 趣味知识/机制冷知识/UGC热评精选 |
| 7 | **符文适配英雄** | 每个符文的Top5适配英雄及排名 |

## 📡 数据源说明

### 1. hextech.dtodo.cn (ARAM.GG)

**数据内容**：符文Tier分级(T1~T5)、精确胜率、选取率、Top5适配英雄、套装系统

**爬取方式**：
- 优先尝试API接口获取JSON
- 备选：解析HTML中的SSR数据
- 兜底：内置158个符文的完整数据快照（2025年3月23日）

### 2. 掌上英雄联盟

**数据内容**：符文icon、等级(白银/黄金/棱彩)、官方描述、数值参数、UGC评分(如8.4分)、热门评论

**爬取方式**：
- 通过HTTP API接口获取
- 需要抓包确认实际接口地址（详见 `docs/掌盟接口分析文档.md`）
- 兜底：内置84个符文的基础描述数据

**如何获取实际接口**：
1. 安装 Charles/Fiddler 抓包工具
2. 配置HTTPS代理证书
3. 打开掌盟APP → 资料库 → 乱斗符文
4. 抓取到的接口地址填入 `config.py` 对应配置

### 3. B站

**数据内容**：符文攻略视频标题/描述，提取推荐理由和黑科技组合信息

**爬取方式**：通过B站搜索API搜索关键词

## 🤖 AI生成内容说明

以下字段由AI规则引擎自动生成初版，标注 `[AI生成-待审核]`，需要运营团队审核修改：

| 内容类型 | 说明 | 审核优先级 |
|---------|------|-----------|
| **人话描述** | 将官方描述翻译成通俗一句话 | 高 |
| **推荐tag** | 如"AOE爆发"、"续航神器" | 高 |
| **短评** | 5-10字推荐理由 | 高 |
| **冷知识** | 趣味机制和隐藏玩法 | 中 |
| **组合黑科技** | 符文搭配组合推荐 | 中 |

## 📈 推荐指数计算逻辑

综合分 = 胜率权重(50%) + Tier权重(30%) + UGC评分(10%) + 选取率(10%)

| 等级 | 综合分 | 推荐icon | 含义 |
|------|--------|---------|------|
| **S** | ≥75 | 👍 推荐选取 | 无脑选 |
| **A** | ≥60 | 👍 推荐选取 | 强力选择 |
| **B** | ≥45 | ✊ 一般 | 稳定可靠 |
| **C** | ≥30 | ✊ 一般 | 中规中矩 |
| **D** | <30 | 🔄 推荐刷新 | 建议换一个 |

## ⚠️ 使用注意事项

1. **数据时效性**：内置数据基于2025年3月23日快照，游戏版本更新后需重新运行爬虫获取最新数据
2. **反爬保护**：所有爬虫已内置1-3秒随机延迟和重试机制，请勿修改为0延迟
3. **掌盟接口**：掌盟APP的实际接口地址可能变更，需要定期抓包确认
4. **AI内容**：所有AI生成的内容仅供参考，发布前必须人工审核
5. **编码**：所有文件统一UTF-8编码，Excel中文正常显示
