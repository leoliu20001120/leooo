# 📊 腾讯控股 (0700.HK) 2025年Q4 深度调研报告

> **发布日期**: 2026年3月25日  
> **报告期**: 2025年10月1日 — 12月31日（2025财年Q4）  
> **数据来源**: 腾讯控股官方财报、电话会议、高盛/招商/海通等券商研报、公开报道

---

## 📋 Executive Summary

腾讯于2026年3月18日发布2025年第四季度及全年业绩报告，呈现出**"稳健增长 + AI全面提速"**的双轮驱动格局。全年营收突破7500亿元，游戏业务收入同比大增22%、国际游戏收入首破100亿美元大关，广告收入保持近20%增速。与此同时，公司正式将AI确立为**唯一值得大规模投入的战略方向**，全年资本开支792亿元，混元大模型3.0计划4月发布，元宝AI应用加速推广。

**一句话总结**: 腾讯在核心业务（游戏+广告）强劲增长的基础上，正"集火AI"——用现有利润为AI基础设施、混元大模型和微信AI生态"下重注"，短期利润增速或受压，但长期护城河有望显著加深。

## 三、AI战略：全面"集火"

### 3.1 战略定位

**AI是腾讯当前唯一的"重注"方向**，贯穿基础模型、应用产品、业务赋能三层。

```
基础层: 混元大模型（自研）+ DeepSeek-R1（开源引入）→ 混元3.0（4月）
产品层: 元宝AI应用 + 微信AI智能体 + QQ浏览器AI + 腾讯地图AI
赋能层: 广告AI化 → 游戏AI化 → 云AI服务 → 企业服务AI化
```

### 3.2 核心投入数据

| 维度 | 详情 |
|------|------|
| **2025年资本开支** | 792 亿元（主要投向AI基础设施） |
| **2025年研发费用** | 850 亿元+（七年累计超4700亿） |
| **Q4元宝+混元投入** | 16 亿元 |
| **全年元宝+混元投入** | 18 亿元（不含业务AI化+云GPU） |
| **2026年AI投资目标** | 至少翻倍（管理层明确表态） |
| **2026年Capex指引** | 占收入"低两位数百分比"（~800-1000亿元） |

### 3.3 AI落地四大方向

```
方向一: 广告AI化
├── 升级广告基础模型（Foundational Ad Model）
├── 提升各流量平台eCPM和广告转化率
└── 结果: 营销服务收入+19%，毛利率达58%

方向二: 游戏AI化
├── AI提升游戏参与度和用户时长
├── AI辅助游戏开发（NPC、关卡设计等）
└── 结果: 游戏收入+22%，远超行业7%均速

方向三: 微信AI生态
├── 搜一搜部署混元+DeepSeek
├── 微信内AI功能持续扩展
├── 终极目标: 微信AI智能体（个人任务助手）
└── 状态: 战略规划阶段

方向四: 腾讯云AI
├── 混元模型对外提供API服务
├── GPU云服务需求旺盛（供应短缺优先内部）
├── 企业服务AI化
└── 结果: 企业服务Q4单季+22%，云全年实现规模盈利
```

### 3.4 AI战略分析

**🟢 看多逻辑**:
- AI赋能已产生实质收入贡献（广告+游戏），不是纯投入期
- 微信14亿+月活是全球最大AI落地场景之一，护城河极深
- 混元自研+DeepSeek开源"双轮驱动"，成本效率领先
- 游戏+社交+支付+小程序的闭环生态，为AI智能体提供天然执行能力
- 现有利润（2600亿+/年）足以覆盖AI投入，无需牺牲核心业务

**🔴 看空逻辑**:
- AI投资翻倍将显著拖累2026年利润增速
- 元宝在AI应用赛道面临激烈竞争（豆包、Kimi、DeepSeek等）
- 微信AI智能体的实现路径和时间表不确定
- GPU芯片供应受限于国际形势，可能制约算力扩张节奏
- 市场对"重投入故事"的耐心有限（财报次日即跌6.8%）
