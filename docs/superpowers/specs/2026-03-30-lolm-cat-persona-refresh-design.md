# LOLM 峡谷猫格 Demo 人格表达重构设计

## 目标
- 保留现有 4 题快速测感与猫种匹配机制。
- 去掉前台对 `MBTI` 的显式露出，避免“4 题就给 MBTI 结论”的违和感。
- 将底层四维匹配包装为峡谷原创语言，让用户感知的是“游戏人格”，不是心理测评术语。

## 核心设计

### 1. 底层保留四维，前台改名
底层仍维持四个可解释维度，但统一改成原创命名：
- `tempo`: 先手开团 ↔ 伺机收割
- `macro`: 运营布局 ↔ 灵感博弈
- `tone`: 铁血决断 ↔ 暖心共鸣
- `style`: 节奏控盘 ↔ 随机应变

这样可以继续复用当前加权匹配逻辑，同时把解释语言完全转到 LOLM 场景中。

### 2. 结果页从“人格类型”改为“峡谷气质”
结果页顶部不再展示字母人格，而展示：
- 你的答题标签
- 你的峡谷气质摘要（2-3 个原创标签）
- 一句过渡文案：AI 根据你的作答倾向与历史对局信号，为你匹配最像的猫种

### 3. 诊断文案改为“行为证据 + 数据佐证”
诊断文案不再引用 MBTI 术语，而改写为：
- 先描述玩家在局内的决策倾向
- 再用一条夸张但合理的数据梗强化记忆点
- 最后把这种倾向映射到猫种风格

### 4. 加载态继续保留“性格 × 数据”逻辑，但不用心理学黑话
加载态改为：
- 读取作答轨迹
- 交叉比对对局信号
- 生成峡谷猫格档案

避免出现 `MBTI`、字母预判等会破坏沉浸感的信息。

## 实施范围
- 重写 `QUESTIONS` 的维度与短标签文案
- 重写 `CAT_TYPES` 的人格描述字段
- 重写 `buildDiagnosis` / `buildComment`
- 重写 `startLoading` / `renderResult` 中的前台人格呈现
- 保留雷达图、PK、猫种匹配的总体结构

## 验收标准
- 页面前台不再出现 `MBTI`、`E/I/S/N/T/F/J/P` 字样
- 用户仍能感知“前面答题”和“后面结果”是同一套逻辑
- 结果页保留高情绪价值和可分享性
- 现有流程与交互节奏不被打断
