## 核心理念

> **一次体验，两层深度：5 秒被王也吊住 → 2 分钟完成体检 → 一份值得分享的报告**

原来「点评 ID」和「体检报告」是两个独立创意，但用户视角看，它们是同一件事的浅层和深层：

| | 点评 ID（浅层） | 体检报告（深层） |
|---|---|---|
| **用户动作** | 输入名字 | 回答 7 个情景问题 |
| **体验时长** | 5 秒 | 2 分钟 |
| **AI 输出** | 一句吐槽 + 星级 | 完整人格报告 |
| **分享物** | 「批命卡」小卡片 | 「体检报告」长图 |
| **传播场景** | 短视频/朋友圈速览 | 社交名片/深度分享 |

融合后不是 1+1=2，是 **1+1=漏斗**。

## 设计亮点：为什么融合比分开做更强

### 1. 漏斗效率：零门槛 → 深度体验

```
输入名字（0 门槛，5 秒）
    ↓ 预期转化率 60-70%（被吐槽后好奇心驱动）
深度体检（2 分钟互动）
    ↓ 预期完成率 80%+（沉没成本 + 对话有趣）
生成报告 + 分享
    ↓ 预期分享率 30-40%（报告包含 ID 点评 + 深度内容，分享价值更高）
```

如果分开做：
- 单独「点评 ID」：分享率高但太浅，看完就走
- 单独「体检报告」：内容好但入口门槛高（谁愿意先回答 7 个问题？）
- **融合后**：用 5 秒体验勾住用户，再用好奇心自然过渡到深度体验

### 2. 内容叠加：报告里嵌入初印象

体检报告第一行就是"王也初印象"（即 ID 点评），形成 **首因效应 → 深度分析** 的叙事弧线：

> "他第一次见你，只看了你的名字就说你在装。现在跟你聊了 7 轮之后，他改主意了——你确实在装，但装得挺像样的。"

这种 **反转/递进感** 比单独的报告更有记忆点。

### 3. 双分享物，覆盖不同场景

| 分享物 | 形态 | 适合平台 | 传播场景 |
|--------|------|---------|---------|
| **批命卡**（STEP 1 产出） | 小图/方图 | 朋友圈、微博、短视频 | "快来看王也怎么吐槽我的名字" → 15 秒看完 |
| **体检报告**（STEP 3 产出） | 长图 | 小红书、QQ空间、微信聊天 | "我的异人体检报告出来了" → 细读+讨论 |

用户可以选择分享浅的（批命卡）或深的（完整报告），或者 **两个都发**——等于一次体验产出两份社交素材。

### 4. 数据闭环

```
批命卡浏览量 → 衡量曝光/引流
    ↓
体检入口点击率 → 衡量浅→深转化
    ↓
体检完成率 → 衡量内容吸引力
    ↓
报告分享率 → 衡量裂变系数
    ↓
新用户进入 → 回到漏斗顶端
```

分开做的话，两个活动的数据是割裂的。融合后是 **一条完整的增长漏斗**。

## 7 个情景问答设计

不是问卷，是**王也跟你聊天**。每个问题根据上一题的回答动态调整语气。

| # | 问题 | 测量维度 | 王也的追问风格 |
|---|------|---------|--------------|
| 1 | "你走在路上，突然看到有人头顶冒出奇怪的光，你会？" | 应激反应（战/逃/冻结） | 选"跑"→"跑得倒是快，练过？" |
| 2 | "如果你有了异能，第一件事做什么？" | 价值观（利己/利他/探索/摆烂） | 选"赚钱"→"俗，但诚实。" |
| 3 | "王也邀你入武当修行，条件是三年不能下山。你？" | 耐性/commitment | 选"不去"→"聪明人。但聪明不一定走得远。" |
| 4 | "甲申之乱中，你的师兄叛变了。你怎么办？" | 忠义观/灰度思维 | 选"杀"→"杀伐果断，但你确定他是叛变？" |
| 5 | "一个人的实力和心性，你觉得哪个更重要？" | 修行哲学 | 不管选啥→"两个都重要，但你的回答暴露了你缺哪个。" |
| 6 | "你更怕孤独，还是更怕被人围着？" | 性格底色（内向/外向） | 选"孤独"→"那你不适合修道。道这条路，很长，也很安静。" |
| 7 | "最后，给自己三个字的评价。" | 自我认知 | 开放题→AI 结合前 6 题分析是否跟自评一致 |

**关键设计**：
- 每个问题不超过 2 个选项 + 1 个自由输入，不给决策疲劳
- 王也的追问是**基于上一题答案**动态生成的，不是固定脚本
- 第 7 题是开放题，让用户觉得"AI 真的在理解我"

## 技术方案

### AI 能力复用

```
┌──────────────────────┐
│   王也知识库 1125+     │
│   + 人设 Prompt        │ ← 共享 AI 后端
│   + 28 种场景回复       │
├──────────────────────┤
│                      │
│  前端模块 1：批命卡    │ ← 输入：ID → 输出：吐槽 + 星级
│  前端模块 2：问答引擎  │ ← 输入：7 轮对话 → 输出：性格向量
│  前端模块 3：报告生成  │ ← 输入：ID 吐槽 + 性格向量 → 输出：长图
│                      │
└──────────────────────┘
```

**核心 Prompt 结构**（简化示意）：

```
[系统] 你是王也，以道家视角与用户对话。
[阶段1-批名] 用户输入ID，用1-3句话吐槽，给出1-5星评级。风格：嘴损但不恶毒。
[阶段2-问诊] 根据7个情景问题与用户对话，每题动态追问。
[阶段3-出报] 综合ID印象+7轮回答，输出JSON格式的完整报告数据。
```

### 开发估算

| 模块 | 工作量 | 说明 |
|------|--------|------|
| AI Prompt 工程 | 3-5 天 | 调教"批名"+"问诊"+"出报"三个阶段 |
| H5/小程序前端 | 5-7 天 | 对话 UI + 报告长图渲染 + 分享组件 |
| 后端 API | 3 天 | 对话状态管理 + 报告生成 + 图片渲染 |
| 视觉设计 | 3-5 天 | 批命卡模板 + 报告模板 + UI |
| 联调测试 | 3 天 | — |
| **合计** | **约 2.5-3 周** | 比分开做两个活动节省约 40% 工作量 |

## 与主方案的嵌入位置

融合后的「异人体检报告」应放在**预热期（第一阶段）**，替代原方案中的「异人鉴定局」：

| 原方案 | 替换为 | 理由 |
|--------|--------|------|
| 4.1「问道王也」AI 对话 | **保留** | 开放式闲聊，定位不同 |
| 4.2「异人鉴定局」人格测试 | → **「异人体检报告」融合版** | 体检报告已包含门派鉴定 + ID 点评，上位替代 |

两者的差异：

| | 原「异人鉴定局」 | 融合版「异人体检报告」 |
|---|---|---|
| 入口 | 直接 5 轮问答 | ID 点评（5秒） → 7 轮问答 |
| 产出 | 异人身份证 | 批命卡 + 完整体检报告 |
| 分享物 | 1 个 | 2 个 |
| 传播层次 | 单层 | 浅层（批命卡） + 深层（报告） |
| 留存钩子 | 无 | 底部接"每日算命"入口 |
