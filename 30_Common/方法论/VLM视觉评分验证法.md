# 🔍 VLM 视觉评分验证法

> 从金铲铲「以铲换X」AI 图片评分验证中提炼。适用于任何需要用视觉语言模型（VLM）做图片分类/评分的场景验证。

---

## 核心理念

**分层抽样 → 逐张看图 → 混淆矩阵 → WebUI 可视化 → Prompt 迭代**

不要一上来就全量跑。先用小样本验证 VLM 能力边界，找到系统性偏差后优化 Prompt，再扩大范围。

---

## 五步流程

### Step 1：样本分层抽样
- 按分类/等级进行**分层随机抽样**（seed 固定，可复现）
- 抽样比例建议：
  - 10 张快速验证（每级 2 张）→ 先证明可行性
  - 20% 抽样（~25 张）→ 正式验证准确率
  - 50% 抽样（~60 张）→ 高置信度验证
- **关键**：确保每个等级都有样本，尤其是边界 case 和小样本等级

### Step 2：VLM 逐张评审
- 每张图片独立发给 VLM，获取结构化输出：
  ```json
  {
    "level": "L3",
    "score": 72,
    "is_target": true,
    "comment": "评语",
    "reasoning": "推理过程"
  }
  ```
- **纯文字 Prompt**（不传参考图）模拟正式上线的评分逻辑
- 要求输出 reasoning，方便分析偏差原因

### Step 3：混淆矩阵分析
统计三层准确率：

| 指标 | 含义 | 目标 |
|------|------|------|
| 大类准确率 | 通过/不通过二分 | ≥95% |
| 精确等级准确率 | 完全匹配 | ≥80% |
| ±1 级容差准确率 | 允许偏差 1 级 | ≥95% |

- 生成 **AI vs 人工 混淆矩阵**，发现系统性偏差模式
- 逐条分析偏差案例的 reasoning，找到根因

### Step 4：搭建评审 WebUI
- 单文件 HTML 实现（参考 [[H5快速原型迭代法]]）
- 核心功能：
  - 等级筛选 + 通过/未通过筛选 + AI≠人工 筛选
  - 等级分布柱状图 + 评审指标概览
  - AI vs 人工混淆矩阵
  - 每张卡片：原图 + AI 评语 + 匹配/不匹配标记
  - 点击卡片展开详情（reasoning + 原始 JSON）
- 自包含版：图片压缩后 Base64 内嵌，可直接发送给业务方

### Step 5：Prompt 迭代优化
根据偏差分析结果优化 Prompt：

| 常见偏差 | 优化方向 |
|----------|----------|
| 创意组合过度加分 | 明确"评判核心物品本身，非整体创意" |
| 材质偏见（低估纸板/毛条） | 加入"材质平等看待"指令 |
| 边界等级混淆 | 增加边界案例描述和区分标准 |
| 评语风格不一 | 加入风格指令（游戏术语/鼓励方向） |

---

## 关键原则

| 原则 | 说明 |
|------|------|
| 📊 分层抽样 | 不能随机选，必须保证每个等级有代表 |
| 🔬 逐张独立 | 每张图独立评审，不要批量传入造成互相影响 |
| 📐 三层准确率 | 大类 > 容差 > 精确，满足业务要求即可 |
| 👁️ 可视化优先 | WebUI 让业务方自己看结果，比发一堆数字有效 |
| 🔄 Prompt 迭代 | 偏差不是模型问题，是 Prompt 问题 |

---

## 实战数据

金铲铲「以铲换X」验证结果：
- 10 张快速验证：大类 100%，精确 80%，容差 100%
- 25 张正式验证：大类 100%，一致率 96%（24/25）
- 59 张高置信：一致率 100%（59/59）
- 系统性偏差：创意组合过度加分、材质偏见（纸板/毛条被低估）

## 适用场景

- UGC 内容审核（用户上传图片分级）
- 商品图片质量检测（电商场景）
- 营销活动图片评分（创意大赛、打卡活动）
- 品牌合规检测（Logo 使用是否规范）
