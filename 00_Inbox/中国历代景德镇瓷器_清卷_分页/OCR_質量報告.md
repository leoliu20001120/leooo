# OCR 識別質量報告

## 方法論

### 三層識別策略
1. **第一層 - 大模型視覺識別（30頁）**：直接用 Claude 的視覺能力閱讀 PDF 原圖，準確率最高
2. **第二層 - Tesseract OCR + 智能修正（386頁）**：用 Tesseract `chi_tra`（繁體中文）模型做基礎識別，再通過規則引擎做後處理
3. **第三層 - 英文交叉校驗**：利用書中英文翻譯反推正確的中文標題（新增80條）

### 為什麼不用 EasyOCR?
之前用 EasyOCR `ch_sim`（簡體中文）模型識別，准確率極低（~20-30%），因為原書是繁體中文。
改用 Tesseract `chi_tra`（繁體中文）模型後，準確率提升到 ~70-80%。

## 已知限制

1. **Tesseract 識別的描述文字可能含有少量噪音字符**（如 `SA`、`BL` 等殘留的英文碎片）
2. **部分頁面為純器物照片（無文字描述）**，這些頁面通常是同一器物的第2-3個角度圖
3. **朝代標注覆蓋率較低（25%）**，因為大多數頁面是附加圖片頁，朝代信息只在主描述頁出現一次
4. **30頁大模型視覺識別（⭐標記）的質量最高**，可作為其他頁面的參考基準
