# OCR 验证报告：前10页（第25-34页）视觉对比

> 验证方法：通过大模型视觉能力直接阅读 PDF 转 PNG 图片，逐页与 EasyOCR 识别结果对比
> 验证日期：2026-04-08

---

## 总体结论

**EasyOCR 的识别质量极差**，几乎每一页都存在大量严重错误。主要问题：

1. **大量汉字误识别**：专业陶瓷术语几乎全部识别错误
2. **繁简混乱**：原文是繁体中文，OCR 用简体模型强行识别，导致大量乱码
3. **部首/偏旁错乱**：很多字被识别成形近但完全不同的字
4. **英文也有误**：连英文描述都有不少错误
5. **结构丢失**：标点、换行、段落结构都不准确

### 准确率估计
- **标题**：约 40-60%（核心词汇多错）
- **尺寸数据**：约 60-70%（数字较准，但"径"常被识别成"铿/矬/徭"等）
- **描述正文**：约 10-30%（大段文字几乎不可读）
- **英文**：约 70-80%

## 根因分析

1. **模型选择错误**：原文是**繁体中文**印刷体，但使用了 `ch_sim`（简体中文）模型，这是最根本的原因
2. **字体特殊**：书籍使用的是宋体/仿宋体印刷，加上年代久远的扫描质量，增加了识别难度
3. **专业术语密集**：陶瓷领域大量生僻字（觚、鈕、髮色、鬱等），EasyOCR 词库覆盖不足
4. **小字描述文字**：图版下方的说明文字字号偏小，扫描分辨率不够时容易出错

## 建议

1. **使用繁体中文 OCR 模型**：如 `ch_tra`（EasyOCR 繁体中文）或更好的方案
2. **改用更强的 OCR 引擎**：如 PaddleOCR、Google Cloud Vision、Azure Computer Vision
3. **最佳方案**：用大模型（如 Claude/GPT-4V）的视觉能力直接逐页识别，准确率远高于传统 OCR
4. **后处理**：即使换引擎，仍需人工校对陶瓷专业术语
