## 2026-04-08: 资产结构与现金流分析框架

**决策**: 采用"轻重资产判定 + 现金流质量评估"双维度分析框架

**理由**:
- 用户关注点明确：①资产重不重 ②现金流多不多
- 轻重资产判定：以固定资产/总资产、资本开支/营收等比率为核心指标
- 现金流质量：以 OCF/净利润、FCF/净利润、资本开支/OCF 为核心指标
- 补充净现金分析，判断公司真实的现金安全垫

**数据处理**:
- 2025 年报数据从多个来源交叉验证（stockanalysis + 雪球 + 新浪 + 东方财富）
- 历史数据（FY 2022-2024）用于趋势对比

**结论**: 泡泡玛特属于"超级轻资产+现金奶牛"模型
