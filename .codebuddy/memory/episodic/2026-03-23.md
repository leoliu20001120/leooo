## 「异人体检站」五行拆字批命系统
- **需求**：用户输入名字后，基于名字做「玄学解读」——拆字分析五行属性，让批命更有仪式感
- **规则体系**（纯前端实现，无需后端）：
  1. **中文字**：双层查找——先查 CHAR_WUXING 常见汉字表（~170 个高频字），查不到则用 Unicode 编码近似笔画 → 尾数分五行
  2. **英文字母**：A-E 木 / F-J 火 / K-O 土 / P-T 金 / U-Z 水（融入西方元素论）
  3. **数字**：天干地支映射（1/2 木，3/4 火，5/0 土，6/7 金，8/9 水）
  4. **偏旁部首**：RADICAL_WUXING 表（备用，目前主要走常见字+编码路线）
- **五行关系**：相生（木→火→土→金→水→木）、相克（木→土→水→火→金→木）
- **批命文案生成**（generateFortuneText）：根据主/辅五行、五行数量、相生相克关系，动态生成 7 种不同话术
- **命数分算法**：基础分 50 + 平衡度加成（max 30%）+ 名字长度微调（max 15）+ 随机抖动
- **UI 升级**（wuxing-analysis 区域）：
  - 逐字五行标注（wuxing-chars）：每个字单独卡片，下方标注五行+对应颜色
  - 五行占比条（wuxing-bar）：彩色分段条形图，按金木水火土配色
  - 图例（wuxing-legend）：五行名 + 数量
  - 五行关系总结（wuxing-relation）：主/辅五行 + 相生/相克关系 + 平衡度百分比
- **彩蛋 ID 兼容**：彩蛋也走 analyzeNameWuxing 获取 _analysis，确保五行拆字区域正常显示
