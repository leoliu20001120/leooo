## 「异人体检站」故事背景入口 — Bottom Sheet 功能
- **需求**：非 IP 玩家可能不了解争议题的故事背景，需要提供可选入口
- **设计原则**：
  - 懂 IP 的人：完全不受干扰，入口极其低调
  - 不懂 IP 的人：通过点击了解故事背景
- **实现方案**：
  - 每道争议题的 CHAT_ROUNDS 数据增加 `storyContext` 字段（第7题终极之问无背景故事，设为null）
  - 每个 storyContext 包含：title / characters[] / story / crux（核心矛盾）
  - AI 提问气泡底部追加「了解这个故事 ›」入口链接（story-hint class），极低调的虚线下划线样式
  - 点击后弹出 Bottom Sheet（底部抽屉），展示故事背景：徽章 + 标题 + 关键人物 + 故事经过 + 核心矛盾高亮卡片
  - 点击遮罩层或抽屉把手关闭
  - 抽屉最大高度 70vh，内容可滚动
- **技术细节**：
  - `addAiMessage()` 新增第三个参数 `roundIdx`，仅在提问消息（非回复）且有 storyContext 时追加入口
  - CSS：story-overlay（毛玻璃遮罩）+ story-sheet（圆角抽屉，translateY 动画）+ story-hint（低调入口链接）
  - HTML：storyOverlay + storySheet + storySheetContent 三个元素
  - JS：openStorySheet(roundIdx) / closeStorySheet() 控制打开关闭

## 「异人体检站」五行拆字批命系统
- **需求**：用户输入名字后，基于名字做「玄学解读」——拆字分析五行属性，让批命更有仪式感
- **规则体系**（纯前端实现，无需后端）：
  1. **中文字**：双层查找——先查 CHAR_WUXING 常见汉字表（~170 个高频字），查不到则用 Unicode 编码近似笔画 → 尾数分五行
  2. **英文字母**：A-E 木 / F-J 火 / K-O 土 / P-T 金 / U-Z 水（融入西方元素论）
  3. **数字**：天干地支映射（1/2 木，3/4 火，5/0 土，6/7 金，8/9 水）
  4. **偏旁部首**：RADICAL_WUXING 表（备用，目前主要走常见字+编码路线）
- **五行关系**：相生（木→火→土→金→水→木）、相克（木→土→水→火→金→木）
- **批命文案生成**（generateFortuneText）：根据主/辅五行、五行数量、相生相克关系，动态生成 7 种不同话术
- **命数分算法**：基础分 50 + 平衡度加成（max 30%）+ 名字长度微调（max 15）+ 随机抖动
- **UI 升级**（wuxing-analysis 区域）：
  - 逐字五行标注（wuxing-chars）：每个字单独卡片，下方标注五行+对应颜色
  - 五行占比条（wuxing-bar）：彩色分段条形图，按金木水火土配色
  - 图例（wuxing-legend）：五行名 + 数量
  - 五行关系总结（wuxing-relation）：主/辅五行 + 相生/相克关系 + 平衡度百分比
- **彩蛋 ID 兼容**：彩蛋也走 analyzeNameWuxing 获取 _analysis，确保五行拆字区域正常显示
