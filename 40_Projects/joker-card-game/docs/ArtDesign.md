# 🎨 小丑牌（Joker Cards）— 美术设计文档

> 版本: v1.0 | 更新: 2026-03-24
> 风格参考: Balatro（复古像素 + 霓虹 + CRT 效果）
> 实现方式: 单 HTML 文件，纯 CSS + Canvas/SVG

---

## 一、整体视觉风格

### 1.1 设计理念

**「深夜赌场里的魔术表演」** — 深沉神秘的背景中，霓虹光芒照亮牌桌，每张牌都带着魔法的微光。玩家仿佛置身一个复古街机厅的赌场角落，CRT 屏幕闪烁着分数。

### 1.2 色彩方案

#### 主色板

|------|------|------|
| 🌑 深空背景 | `#0a0a1a` | 最外层页面背景 |

### 1.3 字体方案

```
主标题字体:   'Press Start 2P', cursive   — 像素复古风，用于游戏标题、关卡标题
正文标题字体:  'Orbitron', sans-serif      — 科技感，用于 UI 标题、按钮文字
正文字体:     'Inter', sans-serif          — 高可读性，用于效果描述、数值文字
数字字体:     'JetBrains Mono', monospace  — 等宽数字，用于分数、金币、计数器
中文备用:     'Noto Sans SC', sans-serif   — 如需中文显示
```

**Google Fonts 导入链接：**
```html
<link href="https://fonts.googleapis.com/css2?family=Press+Start+2P&family=Orbitron:wght@400;700;900&family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;700&display=swap" rel="stylesheet">
```

### 1.4 视觉纹理

- **牌桌**: 深绿毛毡纹理（CSS 噪点渐变模拟）
- **CRT 效果**: 水平扫描线叠加 + 微弱弧形变形（`filter` 实现）
- **光晕**: 所有高亮元素带有 `box-shadow` 外发光
- **暗角**: 页面四角径向渐变暗化（`radial-gradient` 覆盖层）

## 附：与 GDD 对齐的稀有度色彩说明

> GDD 中 game-designer 提到普通为"灰框"，但 team-lead 任务规格指定普通→蓝色边框。
> **最终决策：采用 team-lead 规格**——普通蓝、稀有紫、传说金。蓝色在深色背景上比灰色更具识别度，且与 Balatro 风格一致。

## 三、卡牌设计规范

### 3.1 扑克牌（Playing Cards）

**尺寸**: 宽 70px × 高 100px（CSS 比例 7:10）
**圆角**: 8px
**缩放**: 可通过 CSS `transform: scale()` 调整不同场景大小

```
┌─────────┐
│ A    ♠  │  ← 左上：点数，右上：花色
│         │
│         │
│    ♠    │  ← 中央：大号花色
│         │
│         │
│  ♠    A │  ← 倒转（可选，简化版可省略）
└─────────┘
```

**花色颜色：**
- ♠ 黑桃: `#eef0f2`（白/浅灰）
- ♥ 红心: `#e94560`（霓虹红）
- ♦ 方块: `#e94560`（霓虹红）
- ♣ 梅花: `#eef0f2`（白/浅灰）

**状态样式：**
| 状态 | 样式 |
|------|------|
| 默认 | 白底 `#f8f9fa`，暗灰边框 `#2a2a4a` |
| 悬停 | 微放大 `scale(1.05)`，亮边框 |
| 选中 | 上移 `-12px`，蓝色发光边框 `0 0 12px rgba(74,144,217,0.6)` |
| 打出 | 飞向出牌区动画 |
| 禁用 | 灰色叠加 `opacity: 0.5` |

## 四、动画与特效规范

### 4.1 卡牌交互动画

| 动画名 | 触发条件 | 实现方式 | 时长 |
|--------|----------|----------|------|
| `card-hover` | 鼠标悬停 | `transform: scale(1.08) translateY(-4px)` | 0.15s ease |
| `card-select` | 点击选中 | `transform: translateY(-12px)` + glow border | 0.2s ease |
| `card-deselect` | 取消选中 | 回到默认位置 | 0.2s ease |
| `card-deal` | 发牌 | 从牌堆位置 → 手牌位置，带旋转 | 0.3s ease-out |
| `card-play` | 出牌 | 飞向出牌区 + 缩小消失 | 0.4s ease-in |
| `card-discard` | 弃牌 | 向下滑出 + 淡出 | 0.3s ease-in |

### 4.2 计分动画

| 动画名 | 描述 | 实现方式 |
|--------|------|----------|
| `score-roll` | 分数数字滚动递增 | JS `requestAnimationFrame` 数字插值 |
| `score-pop` | 计分文字弹出 | `scale(0) → scale(1.2) → scale(1)` + `opacity` |
| `score-particle` | 粒子爆发效果 | Canvas 粒子系统，从计分点向外扩散 |
| `chip-multiply` | 筹码×倍率展示 | 左侧蓝色筹码 + "×" + 右侧红色倍率，依次弹出 |

### 4.3 牌型与触发动画

| 动画名 | 描述 | 实现方式 |
|--------|------|----------|
| `hand-name` | 牌型名称弹出 | 从中央缩放弹出，"同花顺！" 金色大字 |
| `screen-shake` | 屏幕震动 | `transform: translate` 随机偏移 2-4px，持续 0.3s |
| `joker-trigger` | 小丑牌触发 | 对应小丑牌 `scale(1.15)` + 强化 glow + 边框颜色脉冲 |
| `gold-gain` | 获得金币 | 金币图标从源头飞向金币计数器 |
| `level-clear` | 通关 | 全屏金色粒子 + 大字 "通过！" |

### 4.4 UI 过渡动画

| 动画名 | 描述 | 实现方式 |
|--------|------|----------|
| `panel-slide-in` | 面板滑入 | `translateX(100%) → translateX(0)` |
| `fade-in` | 淡入 | `opacity: 0 → 1` |
| `button-pulse` | 按钮呼吸 | `box-shadow` 大小循环变化 |
| `neon-flicker` | 霓虹闪烁 | `opacity` 快速跳变模拟灯管闪烁 |

### 4.5 CRT 特效

```
- 扫描线：全屏 repeating-linear-gradient 水平线条
- 暗角：radial-gradient 径向暗化
- 色差：可选 text-shadow RGB 偏移
- 亮度闪烁：微弱 opacity 随机变化
```

### 7.1 CSS 变量命名约定

```css
--color-bg-*      /* 背景色 */

```

### 7.2 CSS 类命名约定（BEM-like）

```
.card              → 基础卡牌
.card--playing     → 扑克牌

.card--planet      → 星球牌

.card__rank        → 点数
.card__suit        → 花色
.card__name        → 名称
.card__effect      → 效果文字
.rarity--common    → 普通稀有度
.rarity--rare      → 稀有稀有度
.rarity--legendary → 传说稀有度
```

### 7.3 Z-Index 层级表

| 层级 | Z-Index | 用途 |
|------|---------|------|
| 基础层 | 1-10 | 背景、牌桌 |
| 卡牌层 | 10-20 | 手牌、槽位中的牌 |
| 悬浮层 | 20-30 | 悬停的卡牌、工具提示 |
| 弹窗层 | 30-40 | 商店界面、结算界面 |
| 动画层 | 40-50 | 飞行中的卡牌、粒子 |
| CRT层 | 100 | CRT 扫描线覆盖层 |
